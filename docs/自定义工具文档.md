# 自定义工具 使用指南（面向玩家 / 地图创作者）

本指南面向**使用这些工具来创建内容的人**，介绍每个工具怎么用、界面上每一个选项是什么意思、以及它的**默认值**（新建条目时自动填入、不填即按此生效）。所有界面文字取自游戏内简体中文翻译键，含义以翻译键和游戏内实际行为为准。

四个工具：**自定义职业工具**、**自定义修饰符工具**、**自定义列车物品工具**、**自定义方块工具**。它们结构完全一致。

---

## 0. 通用操作流程

1. **拿到工具**：用创造模式，或指令 `/sre:give role_tool` / `modifier_tool` / `item_tool` / `block_tool`。
2. **打开编辑器**：手持工具**右键** → 弹出“管理”界面（列表）。
3. **管理界面**（每个工具一个）：列出已配置的所有条目；**新建 X** 创建一个空白条目并进入编辑界面；点列表里某一条进入该条目的编辑界面；**删除（×）** 从配置里删掉；**保存** 写回世界存档；**返回** 退回。
4. **编辑界面**：分多个**页签**，可上下**滚动**；底部有**保存 / 删除 / 返回**。填好后点保存，会自动重载服务端并同步客户端。
5. **改了贴图或模型**后，需要按 **F3+T** 重载资源（贴图在资源加载阶段拼好，不会自动刷新）。
6. **单位约定**：所有“冷却 / 时间 / 间隔”以 **tick** 计（20 tick = 1 秒）；距离以 **格** 计。
7. **默认值说明**：下面每个选项都会标注“默认值”。这就是你新建一个条目时该字段的初始值——绝大多数留空 / 不勾即等于默认值。带 `-1` 多半表示“不限制 / 不修改 / 无门槛”。

## 一、自定义职业工具（`custom_role`）

入口：`自定义职业工具`（手持右键）。编辑器标题“**自定义职业编辑器**”。编辑界面有 5 个页签：**基础定义 / 高级定义 / 能力选项 / 生成选项 / 商店选项**。

> 大量选项是**三态开关**（是 / 否 / 不设置）。默认值里写 `不设置(null)` 的就是三态里没动的状态——表示“继承游戏默认行为”，不要把它当“是”或“否”。

### 1.1 基础定义
- **角色英文ID**：职业的唯一英文 id（如 `my_role`），保存后不可改名（改名会被当成新职业）。
  - 默认值：空（必须填，否则无法保存）。
- **职业显示的名字**：游戏中显示的职业名。
  - 默认值：空。
- **职业的goals**：职业目标描述（介绍页展示）。
  - 默认值：空。
- **职业描述**：职业介绍文本。
  - 默认值：空。
- **自定义标签**（可多个，每行一个）：挂到介绍页的分类筛选（对应翻译键 `screen.roleintroduce.flag.<标签>`，例如写了 `my_group` 就会出现名为 MY GROUP 的筛选标签）；没写翻译时显示成「大写下划线转空格」的原文。`inner.` 开头的标签另有语义（`inner.other_gamemode` = 特殊模式专用等）。
  - 默认值：空列表。
- **初始药水效果**：出生时自带的效果，格式 `效果id,等级;效果id,等级`（如 `minecraft:speed,1;minecraft:strength,2`）。等级 0 = I 级。
  - 默认值：无（空列表）。
- **边框颜色(RGB)**：职业 HUD 边框颜色，三个输入框分别是 R / G / B（0–255）。
  - 默认值：255 / 255 / 255（白色）。
- **是否为平民**：三态开关。设为“是”则该职业算好人方平民。
  - 默认值：是（true）。
- **是否为杀手**：三态开关。设为“是”则该职业属于杀手阵营（中立/平民请填“否”）。
  - 默认值：不设置（null / false）。
- **心情类型**：按钮，切换“真实心情 / 假心情”（影响心情值显示）。
  - 默认值：真实心情（REAL）。
- **心情颜色R/G/B(-1默认)**：覆盖该职业心情条颜色，填 -1 用默认。
  - 默认值：-1 / -1 / -1（用默认）。
- **体力(几倍平民)**：移动体力倍率。
  - 默认值：1（和普通平民一样）。
- **无限体力**：开关。是否不消耗体力。
  - 默认值：关（false）。
- **可看局内时间**：开关。能否在 HUD 看到游戏内经过时间。
  - 默认值：关（false）。

### 1.2 高级定义
> 本页大量为三态开关，默认均为“不设置(null)”，即沿用游戏默认。下面对“是/否”语义关键的注明。

**金币 / 经济类**
- **可看到金币**：能否看到自己/他人金币。默认值：是（true）。
- **被动收入**：是否每回合自动加钱。默认值：不设置。
- **无金币系统**：关闭该职业的金币系统。默认值：不设置。
- **初始金币数(-1不改)**：出生时给多少金币；-1 表示不改（沿用默认）。默认值：-1。
- **击杀奖励的额外金币(0=不给)**：击杀后额外奖励金币数，0 表示没有。默认值：0。
- **击杀不获得金币**：开关。默认值：不设置。

**阵营 / 队伍类（三态，默认均不设置）**
- **中立阵营**、**杀手方中立**、**警长阵营**、**好人方中立**、**家族成员**：决定该职业归属哪个阵营。默认值：不设置。
- **看到队友杀手身份**：能否看穿同阵营杀手。默认值：不设置。
- **启用杀手同伙可见性**：是否让杀手同伙互相可见。默认值：不设置。
- **可被看作杀手同伙**：是否会被其他玩家视作杀手同伙。默认值：不设置。

**尸体查看类（三态，默认均不设置）**
- **看到尸体名字 / 看到尸体物品 / 看到尸体职业信息 / 看到尸体死亡原因 / 看到尸体凶手**：决定上报尸体时能看到多少信息。默认值：不设置。

**通用能力（三态，默认均不设置，除特别标注）**
- **可捡起左轮手枪**、**可跳入井盖**、**可穿越迷雾**、**可触发破坏任务**、**可被中毒**、**在职业轮换中隐藏**、**旁观时可使用技能**、**免疫关灯效果**、**免疫黑暗死亡**、**免疫环境致死**、**免疫摔落伤害**、**可用弓/弩杀人**、**可用三叉戟杀人**、**无法用刀左键击退**、**可使用特殊原版武器**、**可被其他职业随机变换**（提示：若限定特定地图刷新，建议关闭此项，默认：是 true）、**可刷新出多个的特殊警长 / 特殊警长**。默认值：不设置（可被随机变换为 是）。

**数量 / 概率类**
- **占用阵营池数量**：占用的阵营名额。默认值：1。
- **最大自然刷新数量**：本局该职业最多自然出现几个。默认值：1。
- **重复刷新特殊警长的概率**：万分比（0–10000）。默认值：0。
- **结算计入存活好人 / 结算计入存活杀手**：三态。默认值：不设置。

**独立胜利**（仅当“中立阵营”且“非杀手方中立”时才显示该分区）
- **启用独立胜利**：总开关。默认值：关（false）。
- **胜利标语 / 胜利副标语**：胜利时显示的标题与副标题。默认值：空。
- **存活到最后获得独立胜利** 与 **场上只剩自己时获得独立胜利**：二选一互斥，都关时走普通胜利。默认值：都关（false）。
- **只剩自己和指定职业时胜利（用;分隔）**：填职业 id 列表，如 `killer;mafia`。默认值：空列表。判定按场上实际存活构成进行：只要除自己以外的存活玩家全部属于列表中的职业（黑白不计入）即直接取得独立胜利；仍有其它职业存活时则拖延游戏不结算，直到它们全部死亡。该判定不依赖常规胜负（KILLERS / PASSENGERS），因此即使把「结算计入存活好人 / 结算计入存活杀手」都设为是（常规结算会一直停留在继续游戏）也能正常触发。
- **拥有标签时躺床取得独立胜利**：填标签名；空则不据此获胜。默认值：空。
- **拥有指定物品时取得独立胜利**：填物品 id；空则不据此获胜。默认值：空。

**地图 / 任务类**
- **特殊地图类型限制**：按钮循环选择地图特性（如 `ALL` / `UNDERWATER` / `LAB` 等）。默认值：ALL（不限）。
- **小游戏任务独立计时**：三态。默认值：不设置。
- **被透视时隐藏职业信息**：三态。默认值：不设置。
- **是否在轮抽中隐藏身份**：三态。选“是”后，轮抽界面里这个职业显示成「随机」（不暴露真名），并且它释放技能时不会播报职业名。
  - 注意：它**不会把职业排除出轮抽候选池**，职业仍然可能被抽到；要让它不参与轮抽请用**特殊地图类型/模式专用**相关的限制项。
  - 默认值：不设置（沿用职业默认，通常是“否”）。
- **能否小脑别人 / 能否被别人小脑**：三态。默认值：不设置。

### 1.3 能力选项
- **职业初始物品**：物品 id + 数量（可加多行 + / -）。物品 id 先按自定义列车物品解析，找不到再当原版物品。默认值：空（无初始物品）。
  - **解析兜底（延后生效）**：两种都不是时不会丢掉这一条，而是当成「**还没登记的自定义物品**」留一个空壳（显示为通用的“自定义列车物品”，并记住你填的 id）。物品随后在物品工具里建好、索引就绪后，同一个物品栈会自动显示成正确的自定义物品，**不需要重新解析**——也就是可以先写职业、后建物品。
  - 如果 id 真的写错了，它会一直显示成“尚未配置物品数据”的通用物品（物品栏 / 商店里都看得出来），日志里也会有一条 `[CustomRole] Item '...' is neither a loaded custom item nor a vanilla/mod item` 的告警。
- **任务奖励**（每完成 N 个任务给物品）：
  - **每完成N个任务给物品(0关)**：0 表示关闭该功能。默认值：0。
  - **一局最多触发次数**：一局最多发几次。默认值：1。
  - **不限触发次数**：勾选后忽略上面次数限制。默认值：关（false）。
  - **静默发放**：勾选后不发提示。默认值：关（false）。
  - **奖励提示翻译键**：奖励弹窗的提示文本（翻译键）。默认用默认提示。默认值：空。
  - **任务奖励物品**：物品 id + 数量（可多行）。默认值：空。

**直觉系统（本能透视）**
- **可使用本能透视**：总开关。默认值：关（false）。
- **本能透视附带夜视**：三态。默认值：不设置。
- **看别人（关/开）**、**被别人看（关/开）**：每个状态可分别选 `默认 / 无 / 杀手直觉 / 观察者职业色 / 目标职业色` 或自定义颜色；选了自定义颜色会显示 **自定义颜色(hex)** 输入框（如 `FF0000`）。
  - 默认值：看别人/被看 的 关、开 都为 `默认(DEFAULT)`。
- **最大透视范围**：看别人时的透视距离（格），`*` 表示无限。默认值：`*`（无限）。
- **被透视范围**：被别人看的范围（格），`*` 表示无限。默认值：`*`（无限）。
- **是否能无限制透视杀手队友**：开关。默认值：关（false）。

**职业技能**
- **启用职业技能**：总开关。默认值：关（false）。
- **启用切换技能**：开 → 进入“多技能模块”模式（技能 1、技能 2… 可增删模块）；关 → 使用旧的单技能字段。默认值：关（false）。
- 每个技能模块含（单技能模式字段相同，只是全局一份）：
  - **技能名称**：HUD 显示在冷却上方的名字。默认值：空。
  - **技能执行指令**：多条，支持 `<player>`（释放者）等占位符。默认值：空。
  - **技能冷却(秒)**：冷却时长（tick 换算）。默认值：30。
  - **技能初始冷却(秒)**：开局先冷却多少秒。默认值：0。
  - **延迟执行秒数**：释放后过多少秒再执行延迟指令。默认值：0。
  - **延迟执行指令**：延迟后执行的指令。默认值：空。
  - **游戏结束执行指令**：该局结束时执行的指令。默认值：空。

### 1.4 生成选项
- **双向互斥职业 / 单向互斥职业 / 绑定生成职业**：填职业 id（逗号分隔）。双向互斥=双方不共现；单向互斥=本职业不会和已刷出的这些职业共现；绑定=和这些职业绑定同生。默认值：空列表。
- **双向相关职业 / 单向相关职业 / 移除相关职业**、**双向相关修饰符 / 单向相关修饰符 / 移除相关修饰符**：介绍页上展示的关联（逗号分隔）。默认值：空列表。
- **移除关联职业 / 清空关联职业**：清掉绑定生成职业里某些项（清空在添加之前生效）。默认值：移除空 / 清空关（false）。
- **任务刷新黑名单 / 任务刷新白名单**：用按钮挑选任务类型，控制该职业能刷出哪些任务。默认值：空列表。
- **限定地图刷新**：逗号分隔的地图 id 列表。默认值：空。
- **组合地图特性**：如 `UNDERWATER,LAB`。默认值：空。
- **特性需全部满足**：勾选=AND（全部满足才刷），不勾=OR。默认值：勾选（true）。
- **自定义生成条件**：如 `snow = true`、`features contains LAB`。默认值：空。
- **条件需全部满足**：勾选=全部满足，不勾=任一满足。默认值：勾选（true）。
- **使用万分比概率 / 使用百分比概率**：切换概率单位开关。默认值：关（false，即用百分比）。
  - 对应 **刷新概率(%)**（0–100）：默认值 100（必定刷，受其它限制约束）。
  - 或 **万分比概率**（0–10000）：默认值 100（必定刷）。
- **最少玩家启用数(-1=无门槛)**、**最多玩家启用数(-1=无上限)**：默认值：-1 / -1。

### 1.5 商店选项
每个商品一行，按钮循环切换 **类型**：`item`（物品）/ `psycho`（疯魔）/ `blackout`（关灯）/ `monitor_fail`（监控失灵）/ `custom`（自定义指令）。
- 商品 **类型**：默认值 `item`。
- **商品价格**：默认值 0。
- **冷却(秒)**（仅 item / custom 有）：默认值 0。
- **禁止重复购买**（仅 item 类型，可切“允许/禁止”）：默认 **允许**（allowDuplicate=true）。
- `item` 类型额外：**商品物品ID**：默认空。
- `custom` 类型额外：**商品显示名称**、**商品图标ID**、**购买执行指令**（多条）：默认空。
- 底部 **+ 添加商品** 新建一行。

> **商品物品ID 的解析顺序**：先按**自定义列车物品**的 id 解析，找不到再当原版 / 模组物品，都不是就留一个「还没登记的自定义物品」空壳（同 1.3 的兜底，显示为通用的“自定义列车物品”）。所以：
> - 商品里可以填**还没建好**的自定义物品 id：条目会正常出现在商店里（先显示成通用自定义物品），物品建好后就自动正常。
> - 自定义列车物品与自定义职业 / 修饰符之间是**有先后的**：注册职业时会按 id 查一次物品索引，所以物品索引一定先就绪（服务器启动、以及 `/sre:reload` 各子命令都按 **物品 → 方块 → 职业 → 修饰符** 的顺序，并且重载物品会连带重新注册职业与修饰符）。用编辑器保存物品后不需要手动再保存一次职业。
> - **每局开局时会再重建一次商店**（服务端与客户端都做，做法与内置职业商店的 `RoleShopHandler.shopRegister()` 一致）：这时内容早已加载 / 同步完毕，所以即使之前注册时物品索引还没就绪，开局后商店里的条目也是对的；重建只替换商店列表，不会重新注册职业，也不影响已经分配好的职业。改完商店条目保存后无需等下一局——保存时就会重建一次（见上一条）。

## 二、自定义修饰符工具（`custom_modifier`）

入口：`自定义修饰符工具`（手持右键）。编辑器标题“**自定义修饰符**”。编辑界面页签：**基础 / 关联 / 生成 / 生成限制 / 触发与内容**。

### 2.1 基础
- **英文ID**：修饰符唯一英文 id。默认值：空（必填）。
- **中文名称 / 描述**：介绍页展示。默认值：空。
- **自定义标签**（可多个，每行一个）：挂到介绍页的分类筛选（对应翻译键 `screen.roleintroduce.flag.<标签>`）；没写翻译时显示成「大写下划线转空格」的原文。默认值：空列表。
- **颜色(RGB)**：默认 255/255/255（白）。
- **隐藏修饰符**：在介绍页与 HUD 隐藏。默认值：关（false）。
- **仅标记使用**：开启后忽略“触发与内容”页签（配置保留），仅作为标记挂在玩家身上。默认值：关（false）。

### 2.2 关联
- **双向关联职业 / 单向关联职业 / 单向移除关联职业**、**双向关联修饰符 / 单向关联修饰符 / 单向移除关联修饰符**：介绍页上展示的关联（逗号分隔 id）。默认值：均为空列表。

### 2.3 生成
- **局内最大刷新数量**：本局该修饰符最多出现几个。默认值：1。
- **生成概率(万分比)**：0–10000。默认值：10000（必定刷，受其它限制约束）。
- **最少玩家启用数(-1=无门槛)**、**最多玩家启用数(-1=无上限)**：默认值：-1 / -1。
- **限定地图**：逗号分隔的地图 id。默认值：空列表。

### 2.4 生成限制
- **双向互斥修饰符 / 单向互斥修饰符**：双方/单向不会出现在同一玩家身上。默认值：空列表。
- **不作用于特定职业**、**仅作用于特定职业**：用逗号分隔 id 限制作用对象。默认值：空列表。
- **阵营限制**：一个阵营一个按钮（相邻的两个自动并排成一行），点一下在
  **不限 → 仅给该阵营刷新 → 不给该阵营刷新** 之间循环，当前状态写在按钮上（不限 / 仅给 / 不给）
  并配一个带颜色的状态方块（– 不限 / ✓ 仅给 / ✗ 不给）。
  - 两个方向**互斥**：同一个阵营不会既「仅给」又「不给」（切到新的状态时会自动把另一边的旧记录清掉）。
  - 按钮标题就是阵营（平民 / 警长 / 中立 / 好人方中立 / 杀手方中立 / 特殊中立 / 杀手）。
  - 默认值：全部为「不限」（两个列表都为空）。

### 2.5 触发与内容

这一页按「触发组」组织：**每组 = 一份触发条件 + 一份触发内容**，条件满足时只执行**本组**的指令与效果，
组与组之间互不影响。于是可以写「计时 30 秒 → 给 A；击杀 3 人 → 给 B」这种多条对应关系。

- **＋ 新增触发组** 新建一组（默认是「有条件触发」并带一条「自动定时」条件，避免新组误判成全局组）；
  组头会标出「第 N 组」和「N 个条件 / 全局组」，组头右侧的 **×** 删除整组。
- **本组类型**（每组卡片里的第一行）：在 **有条件触发** 与 **全局常驻（无条件）** 之间切换，切换后即时重建
  页面（条件行 / 属性行会跟着出现或隐藏）。
  - **全局常驻**：拥有该修饰符即持续生效（药水效果常驻、属性常驻，指令只在获得时执行一次）。
    这一组无条件，也不参与条件判定。
  - **有条件触发**：满足本组条件时才执行本组内容；条件一条都没有时这一组不会触发（界面会提示）。
- 组类型写在 JSON 的 `groups[].global`（`true` = 全局常驻）。**老配置没有这个键**时按旧规则推断：
  条件为空即全局组 —— 所以老的全局修饰符行为不变。
- 老配置（单个扁平条件 + 内容）在读取时会自动迁移成「一个组」，不需要手工改 JSON。

#### 每组的条件
- 顶部 **逻辑：与 / 或** 决定多条条件如何串联。默认值：与（AND）。
- 点 **＋ 添加条件** 增加一条；每条先选 **条件类型**，再填对应参数。
- 每条条件默认值：类型 `自动定时(TIMER)`、数值参数 `0`、字符串参数 `空`、比较方式 `等于(EQUALS)`、时间锚点 `白天(DAY)`、与下一条逻辑 `与(AND)`、定时概率间隔 `10` 秒、触发概率 `10000`（必定）。
- 条件类型（共约 45 种，按界面名称与默认参数含义）：
  - **自动定时**：每 value 秒触发一次。
  - **时间锚点**：以游戏开始为基准，第 value 秒（经过秒数）满足条件时触发一次。
  - **有特定物品**：stringValue=物品 id。
  - **死亡**、**使用物品**(stringValue=物品id，留空=任意)、**聊天栏说话**(stringValue=关键字，留空=任意发言)、**金币数量**(比较value)、**击杀过玩家**(value=击杀数)、**玩家数量**(全局, 比较value)、**存活玩家数量**、**潜行状态**、**疾跑状态**、**拥有特定药水效果**(stringValue=效果id)、**定时概率**(每 intervalSeconds 秒以 chance 万分比概率)、**世界时间**(DAY/NOON/SUNSET/NIGHT/MIDNIGHT)、**心情值**、**疯狂模式**、**中毒**、**感染**、**护盾值**、**是否有任务**、**连续完成任务数**、**活跃疯狂玩家数量**、**关灯状态**、**监控失灵**、**完成特定类型任务**(stringValue=任务类型)、**受到玩家伤害**、**受到非玩家伤害**、**游戏经过时间**(同时间锚点的绝对秒数)、**触发过假毒**、**弱效护盾**、**被同阵营击杀**、**被特定阵营击杀**(stringValue=阵营名)、**被特定职业击杀**(stringValue=职业id)、**被拥有特定修饰符的玩家击杀**(stringValue=修饰符id)、**死亡倒计时复活**(value秒后触发并复活)、**死亡倒计时**(value秒后触发不复活)。
  - 数值比较可选：**等于 / 大于 / 小于 / 大于等于 / 小于等于**。
- **触发后移除该修饰符**（每组独立，只在「有条件触发」的组里显示）：本组触发一次后自动卸下。默认值：关（false）。

#### 每组的内容
- **＋ 添加指令**：本组触发时执行的指令（`<player>` = 拥有该修饰符的玩家）。默认值：空列表。
- **＋ 添加药水效果**：全局组=持续到失去修饰符（不显示时长格）；条件组=按持续秒数。每行：效果 id + 等级(0=I) + 持续秒数。默认：效果空 / 等级0 / 持续10秒。
- **＋ 添加属性**：**仅全局组可用**，失去修饰符后自动重置。每行：属性 id（如 `minecraft:generic.movement_speed`）+ 数值。默认：空 / 0。
- 同一个修饰符的多个组可以各有一个「死亡倒计时」，HUD 会分行显示。

## 四、自定义方块工具（`custom_block`）

入口：`自定义方块工具`（手持右键）。编辑器标题“**自定义方块**”。编辑界面页签：**基础 / 外观 / 属性 / 事件**。

### 4.1 基础
- **方块 id**：英文（如 `my_block`，`/sre:give block <id>` 用）。默认值：空（必填）。
- **显示名称**：物品栏里的名字，留空用默认。默认空。
- **物品说明**：每行一条。默认空列表。
- **按放置朝向旋转**：开启后按放置者朝向 4 向水平旋转。默认值：是（true）。

### 4.2 外观
- **继承方块**：填方块 id（如 `minecraft:oak_planks`），模型/碰撞/音效都跟随它。默认空。
- **资源包贴图**：把方块渲染成整方块贴图（与继承方块冲突时优先本项）。默认空。
- **发光等级**：0–15，0 = 不发光。默认值：0。
- **发光受关灯影响**：开→关灯期间亮度归零并闪烁；关→亮度恒定。默认值：关（false）。
- **预览**：实时显示，显示用无默认值。

### 4.3 属性
- **无碰撞（可穿过）**：开启后玩家与生物可直接穿过（右键仍可选中）。默认值：关（false）。
- **屏蔽天空光**：开启后像不透明方块一样，下方不被天空照亮。默认值：关（false）。

### 4.4 事件
可挂多个事件（同类型也可多个，上限 32 个），点 **＋ 添加事件**。每个事件先选 **事件类型**：
- **右键点击 RIGHT_CLICK**，**踩踏 STEP**，**靠近 PROXIMITY**（靠近类半径上限 32 格，需服务端扫描，有性能开销）。

每个事件默认与可选字段：
- **事件类型**：默认 右键点击（RIGHT_CLICK）。
- **指令列表**：每行一条，`<player>`=触发的玩家，`~ ~ ~`=其坐标。默认空。
- **冷却**(tick)：默认 0（无冷却）。
- **仅潜行时触发**：仅右键类型有，默认 否（false）。
- **触发后消耗方块**：仅右键类型有，默认 否（false）。
- **触发半径**(格)：仅靠近类型有，默认 4.0（最小 1.0）。
- **每个玩家只触发一次**：踩踏/靠近类型有，默认 否（false）；需重进世界或重载才重置。
- **仅游戏进行中生效**：默认 否（false）。
- **触发条件**：**限定职业**（逗号分隔，留空不限）、**限定阵营**（阵营名，留空不限）、**全部留空即不限制**。默认均为空。

> 注意：`requiredRoles`/`requiredTeams` 里若出现空行会被自动忽略；但务必保证没有“写成空的限定”导致事件永远不触发。

## 五、保存与同步提示
- 在编辑界面点 **保存** 后，配置写回世界存档并自动重载，同时把一份副本同步到客户端 `config/` 目录（离线/编辑器读取贴图与模型用）。
- 若修改了**贴图地址 / 模型地址**，必须按 **F3+T** 重载资源，否则看到的还是旧贴图。
- 所有时间字段单位为 **tick**（20 tick = 1 秒），距离单位为 **格**。
- 物品 id / 方块 id / 职业英文ID / 修饰符英文ID 不可与已有条目重名，否则保存会提示“编号已被占用”。
- 三态开关（职业/修饰符里大量存在）的“默认（不设置）”不等于“是”也不等于“否”，表示沿用游戏内该职业/修饰符的默认行为；需要明确生效时请手动选“是”或“否”。
