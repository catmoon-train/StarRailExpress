# 训练场：本地单人与专服独立训练营

训练场支持独立本地存档，以及由 VirtualProxy `TRAINING` 角色显式启用的专服。需要安装与本项目相同的 Carpet `1.4.147+v240613`；缺少后端时拒绝开放训练营，不会以共享场地或普通怪物替代。

## 进入与退出

- 主菜单「前往训练场」：首次复制内置地图到 `saves/SRE_TrainingGround`，以后继续使用该训练存档。同名普通存档不会被覆盖。
- 单人 ESC：确认保存并退出原世界后进入训练场。
- 多人 ESC：配套 VirtualProxy 将入口转为保队进入训练子服；不支持的服务器仍按原有确认流程处理，正在排队时不会误断线进入本地存档。
- 训练场内 ESC 入口改为「训练控制面板」；`LimitedInventoryScreen` 背包旁也有专用入口，仅在训练场中显示。也可以使用客户端命令 `/sre:training`，不新增快捷键。
- 本地管理仍仅限未公开到局域网的集成服主人。专服管理只在 Proxy 的 `TRAINING` 节点启用；普通专服不能通过客户端请求开启。

## 地图

约 160×128 格的「列车整备训练站」，活动面 Y=65。原版方块为主体，搭配已有列车装饰，固定白天、晴天、不自然刷怪。

| 区域 | 用途 |
| --- | --- |
| 西南候车大厅 | 安全出生、休整、操作指引；假人不追入大厅 |
| 西北射击靶道 | 5、10、20、30、40 格距离标记及移动靶路线；距离标记不代表所有枪都能射到对应距离 |
| 东北掩体对战区 | 高低掩体、台阶、绕行通道，练习追击和射击 |
| 南侧列车区 | 三节连通车厢：座席、餐车、卧铺，练习转角与狭窄走廊 |

可以通过面板快速传送到各区；选择战斗区时本组假人随之迁移。玩家越界或跌落返回大厅。默认冒险模式，不自动赋予创造或无敌。

## 控制面板

- 面板使用固定分页、常用操作栏和独立列表/详情，避免在长表单中反复滚动。配置即时请求服务端，不需要另外保存；快照刷新时保留搜索、分页和简介阅读位置。
- **道具**：分类、名称/ID 搜索、领取单件或一组、常用训练套装。目录来自服务端物品注册表、职业初始物品、商店和已加载自定义物品；保留物品组件，排除方块及编辑工具。背包已满会提示。
- **我的职业**：按阵营筛选、查看介绍并应用职业；清除旧职业状态、初始化新 RoleData 并发放初始物品。可恢复状态、重新初始化职业、补充训练金币。具有地图条件的职业会显示限制提示，不保证在本图触发所有特殊机制。
- **敌人**：0–32 个 Carpet `player`，默认 5 个静止敌人；数量快捷调整，显示「假人 1」等短名称。可设置默认职业、装备与行为，也能逐个调整、复活/重试或移除；支持一键复活死亡/失败假人，不重置自己或整张地图。
- **训练设置**：区域传送、暂停 AI、自动复活、1–30 秒复活延迟、手动重置技能和物品冷却、友伤惩罚、清理掉落物/尸体、重置本轮以及备份重建地图。
- **无限体力 / 速度 I**：两个独立开关，默认关闭并分别保存；只作用于本营真人主人，不影响假人、其他营地或正常对局。开启体力辅助时补满当前体力，并使用已有无限体力效果同步客户端；速度使用已有速度效果（I 级）。换职业/重生后按设置重新应用，关闭或会话结束时撤销自己的辅助租约，不覆盖职业/道具的同类或更强效果。原有禁用体力等职业/状态限制仍遵循正常规则。
- **无冷却**：在「训练设置 → 本营设置」单独开关，默认关闭并保存；开启后仅对本人持续清除统一技能、各独立技能和物品冷却，有实际冷却变化才同步。保留「重置自身冷却」的一次性操作。关闭后新产生的冷却正常生效，不恢复已经清掉的旧计时；不补充弹药/技能次数、不重置持续状态，也不绕过职业自有的非统一机制。
- **金币 +1000**：顶部常用操作栏每次在本人当前训练余额上增加 1000，可重复点击；不会把较高余额重设为 1000，并对整数上限进行饱和保护。训练金币不转化为正式奖励。

默认使用真实弹药与冷却（除非本人启用「无冷却」），自动复活开启、延迟 3 秒，友伤惩罚关闭。「暂停 AI」只暂停自主行为，不禁止自动复活；关闭「自动复活」后仍可手动复活。护盾、免疫与正常职业伤害规则不被强行跳过。

## 假人行为与边界

1. **静止**：无自主移动或攻击，但可正常被命中并触发职业被动。
2. **移动靶**：按区域路线往返/巡逻，遵循实际碰撞。
3. **基础对战**：在战斗区域内锁定训练玩家、追击、绕掩体、近战或常规手枪射击；安全区、死亡、暂停或目标失效时停手。射击遵循服务端视线、射程、冷却和职业规则。

本功能不是全职业智能对战：不替所有职业编写主动技能决策，也不支持所有特殊武器的自主操作。假人装备在生成、重置或重新配置时发放，不逐 tick 无限补充弹药。

死亡假人优先**原地复用同一 ServerPlayer、UUID 和连接**，直接调用与 `tmm:game revive` 相同的 `GameUtils.revivePlayer`，随后恢复该槽位的职业、行为和装备。正常死亡复活不退出、不重新登录、不重新获取皮肤/档案；复活完成后按死者 UUID 删除本营内属于该假人的所有已加载尸体，不删除其他玩家的尸体。自动、单个和全部复活共用此路径，每 tick 最多原地复活两个，批量操作只排队。只有确实已断线/移除或首次生成失败的槽位才走受限异步补建；缩减数量、移除、重置和退出仍会按预期回收对象。

对本会话管理的假人，原版致死伤害在 Carpet 自动断开连接之前转为正常的游戏死亡/旁观状态，保留职业防御和死亡事件，等待同一对象复活；不改变普通真人或其他系统假人的死亡流程。复活失败保留错误和原身份供手动重试，异常会记录主人、槽位、操作与堆栈。

普通对局的入服修正（立即、约 0.5 秒和 3 秒后的检查）不处理训练世界；营地主人和假人的出生、位置与游戏模式由训练会话负责，避免被误认作中途加入正式对局而切成旁观者。

训练假人账号统一生成小写；在线识别、归属校验和取消回收共用忽略账号大小写的匹配，并继续严格校验已绑定 UUID 和 Carpet 假玩家类型。配置失败时停止自动复活，保留面板错误供手动重试；旧假人未确认退出时拒绝生成替代者，防止玩家列表不断膨胀。更新此修复后应退出训练世界再重新进入（专服重启训练节点），不需要重建地图或删除训练设置。

首次创建/断线补建时，档案与皮肤查询在原版 I/O 线程池运行，复用原版缓存；不再调用会先同步查询 Mojang 的 Carpet `createFake`。查询超过 3 秒、失败或不存在账号时使用固定离线档案，服务器线程不等待网络。主线程仅消费已完成的结果，每 tick 最多实际创建两个假人；退出、缩减数量、重置和超时会取消消费资格，迟到查询不创建实体。正常死亡原地复活不重新查询档案。网络超时时可能使用默认皮肤，不影响训练。

## 数据、重置与备份

设置保存在训练存档的 `training-settings.json`。在线假人、生成任务和死亡倒计时不跨会话保存。退出/重置会取消旧生成并只回收本训练会话管理的假人，不回收其他职业创建的实体。

训练不进行正式胜负、独立胜利结算、自动发车或会议，不记正式战绩，不推进通行证与数据库奖励。统计在不落盘的沙箱中运行；返回普通世界后恢复正常数据路径。

「重置本轮」只重置训练对象和状态；「重建训练场」会退出当前训练存档，成功执行 Minecraft 原版世界备份后，从内置模板重建。备份失败不继续。训练模板升级不会无提示覆盖旧地图。

## 专服：8 人独占与场地复用

- 每台训练子服最多 **8 名真人**，预约转服也占位。Carpet 假人和职业生成的假玩家不占真人名额；每人的 0–32 个训练假人仍分别管理。
- 固定使用 `starrailexpress:training_0` 至 `training_7` 八个独立维度，同一时刻一个维度只租给一位真人。不是同一世界中的远距离分区，因此角色世界组件、地图配置、假人目标和清理互相隔离。
- 场地池按 UUID 幂等分配，满员拒绝第九位；释放必须匹配当前租约代次，旧连接/旧任务不能释放已经复用的场地。设置存于 `training-settings/<uuid>.json`。
- 模板只解码缓存一次，各营按全服总预算分 tick 建设。建设中玩家在自己维度的等待位置，没有面板和对战权限；完成的地图保留并复用，不在每次加入时重新复制整张地图。
- 离开时先停止本营 AI、取消待生成假人、回收角色/临时实体和世界状态，再释放租约。清理失败时保留租约，不把未安全回收的场地交给下一位。关闭一个营不会停止其他营。
- 面板请求只接受本人、当前租约及匹配世界；枪刀、常规伤害和训练模式击杀均拒绝跨营玩家目标。专服面板禁用本地存档重建。
- 同批更新中控、`virtual_proxy` 桥接、SRE、客户端和 Carpet，在独立服务端配置 `server.role=TRAINING`。后端或固定维度缺失时拒绝启用；不要关闭转服准入。现有单人存档无需迁移。

上线前需实际验收 8 人同时进入互不见面、第 9 人拒绝、断线后复用、旧回调不影响新租户、真人/假人死亡重生、每人独立面板与友伤设置，以及 8 人同时保队进入正式服。自动化测试不能代替这些实机验收。
