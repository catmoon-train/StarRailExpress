# 23 · 追猎循环（已删除，留作参考）

> 状态：**当前版本没有追猎循环，也没有右上角的潜伏/蓄力/突进/后摇 HUD。**
> 本文只记录它原本是什么、为什么删除、以及被什么替代。

## 1. 原本是什么

截流者（追捕方）曾有一套四相状态机，用「锁定值」把贴身追击量化：

```text
STALK(潜伏) ──起手蓄力──▶ CHARGE(蓄力) ──松手──▶ LUNGE(突进)
   ▲                          │                    ├─命中─▶ RECOVER 8t (后摇)
   └──────────────────────────┴────────────────────┴─挥空─▶ RECOVER 24t
```

| 相位 | 移速倍率 | 锁定值 |
|---|---|---|
| `STALK` 潜伏 | ×1.00 | 有目标累积，无目标衰减 |
| `CHARGE` 蓄力 | ×0.55 | 每 tick −2 |
| `LUNGE` 突进 | ×1.00 | 不变 |
| `RECOVER` 后摇 | ×0.85 | 不变 |

**锁定值**：24 格内按距离（≤8 格 ×1.0 / ≤16 ×0.75 / ≤24 ×0.5）× 目标移动（疾跑 ×1.4 / 移动 ×1.0 / 静止 ×0.6）× 2.0 每 tick 累积，无目标每 tick 衰减 3。
**扑击**：锁定满 100 时下一刀升级——判定 +2 格、倒地 +200 tick、命中免后摇、锁定清零。
**受害者心跳**：锁定 ≥50 时只给目标本人播 `WARDEN_HEARTBEAT`，间隔 40 → 12 tick。

## 2. 为什么删除

1. **玩家读不懂**：右上角那块区域要同时显示锁定环、相位名、扑击就绪、本能倒计时，实际游玩时没人有空看。实测反馈是「潜伏」这个词本身没有可操作含义——它不代表你正在做什么。
2. **和职业重复**：锁定值只服务于「扑击」和两个职业被动（血腥味、丝线感知），而这两个职业现在已被新的追捕职业取代。
3. **拖慢核心循环**：蓄力 ×0.55 的减速让追击变成「走两步停一下」，与「截流者靠截货、迟滞充能、封门控制节奏」的设计目标相反。
4. **HUD 位置冲突**：它固定占在右侧小地图正下方，把技能徽章和信标进度挤得很紧。

## 3. 被什么替代

- **攻击**：右键蓄力 16 tick（0.8 秒）→ 松手立即判定，没有前摇、没有相位、没有锁定值。挥空至少 3 秒冷却，命中至少 6 秒冷却并附带 3 秒缓慢 I。
- **压迫感**：由**追捕职业的被动与主动技能**承担（见 [24 职业体系](24-classes.md)），例如视野压制、破板加速、冲刺抓取。
- **受害者反馈**：保留恐惧半径的镜头轻颤与「颤抖 I」光环，但不再有随锁定值加速的心跳。
- **HUD**：右上角不再有狩猎面板，只保留小地图；追捕职业信息走技能徽章与底部两行紧凑信息。

## 4. 代码存档

已删除：`combat/EchoHuntLoop.java`、`client/EchoHuntHud.java`、`EchoRoleData` 的 `huntPhase/huntFocus/huntPhaseUntil/huntInstinctUntil/huntEmpowered` 投影与 NBT 字段、`EchoMatch.Member.hunt`。

保留且仍在使用：`anim/EchoHuntAnim`（第一/第三人称抬刀与擦刀曲线）、`anim/EchoHuntFx`（刀光/血花/冲击环）、`EchoHuntPayload`（动作广播）——它们只负责表现，不参与任何判定。

如果将来要恢复锁定值，必须先回答：它给玩家提供什么**可操作**的决策？只做「越贴越强」的数值累积不足以支撑一个 HUD 区域。
