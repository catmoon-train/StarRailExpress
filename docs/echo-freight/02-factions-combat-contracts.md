# 02 · 身份、战斗、契约与个人结算

> 依赖：[01 总则](01-gameplay.md)。本文是玩家权限、两次机会、掉线及契约规则的权威来源。服务端接法见 [06](06-server-architecture.md)，不是复制普通职业死亡事件实现整套玩法。

## 1. 权限矩阵

三个专属角色拟为 `echo_carrier`、`echo_interceptor`、`echo_broker`，命名空间均为 `noellesroles`。都关闭金币、商店、本能身份透视、心情任务、普通武器拾取与普通职业随机替换。

| 动作 | 托运者 | 截流者 | 投机客 |
|---|---|---|---|
| 普通晶体采集/拾取/提交 | 是 | 否；不能销毁或藏普通晶体 | 否 |
| 黑晶采集/提交 | 否 | 否 | 仅走私商本人；黑晶不交易 |
| 信标守点加速 / 迟滞充能 | 加速 | 迟滞充能 | 都不能 |
| 拿钥匙、开核心门、交易、开包 | 是 | 是 | 是 |
| 救倒地者 | 是 | 否 | 是，不要求特定契约 |
| 致命攻击 / 推挡 | 不能致命；可推挡 | 截流器 | 都不能；靠卡牌自保 |
| 主撤离区计数 | 计 Q | 不计 | 不计；成功契约可在退场点离场 |
| 拾取跨阵营卡牌 | 可以，占格，但不能用 | 同左 | 同左 |

正常客户端默认不显示陌生人的真实阵营颜色；狼看见狼队友，托运者不直接识别投机客或狼。狼的可见武器、攻击和任务信号会暴露行为。交易成交不免费验明阵营，契约进度只在成交后按真实身份记账。底层职业 ID 的既有同步边界见 07。

## 2. 状态与战斗基线

### 2.1 生命状态

```text
HEALTHY ─首次有效命中→ DOWNED ─救起→ WOUNDED ─再命中→ ELIMINATED
                         └45 秒无人救援→ ELIMINATED
HEALTHY / WOUNDED ─有效撤离→ ESCAPED（仅托运者）
契约已成功的投机客 ─退场点确认→ RETIRED
```

`connected` 是正交状态，不以 `OFFLINE` 覆盖倒地/受创事实。健康值不作为本模式机会数。首次倒地不调用完整死亡流程、不生成尸体、不转旁观、不记一次正式击杀；最终淘汰才调用标准死亡，倒地记模式回放事件。

### 2.2 截流器

- 专用工具 `EchoCutterItem`，不占六格背包，固定快捷栏 0；不能交易、丢弃或用于其它模式。建议继承已有 `KnifeItem`，覆写释放钩子并声明此次释放已处理，阻止默认刺杀再次执行。
- 按住使用至少 12 tick（0.6 秒），松开执行一次服务器视线命中。射线从眼睛出发，最远 2.75 格，只取首个未被方块挡住的有效玩家；不接受客户端声称的命中、伤害或距离。
- 达到蓄力要求的挥击无论命中与否均进入 50 tick（2.5 秒）冷却并发出近距挥击声。未蓄满不攻击、不进冷却。
- SAFE、旁观、倒地、已退场、受控、正在交易确认/开包引导、错误工具或冷却中均拒绝。主动攻击会先取消自己的资源引导和交易，不允许一边迟滞一边挥刀。
- 友军截流者、已撤离者、倒地者不构成有效击倒目标；倒地者不挡射线去攻击其后的活人，但实体和墙的普通遮挡仍有效。一次挥击最多处理一名玩家。
- 禁止默认拳击/其它武器绕过规则；即使外部物品发起普通 `GameUtils.killPlayer`，模式边界仍统一路由。

### 2.3 倒地与救援

| 项 | 默认规则 |
|---|---|
| 首次倒地 | 取消引导、交易、卡牌待使用；晶体/黑晶与钥匙全部掉落；普通卡与包保留 |
| 倒地时限 | 900 个模式 tick（45 秒）；暂停冻结，救援不暂停流血 |
| 倒地权限 | 原地不可移动/跳跃/攻击/使用/开包/交易；允许转视角、呼救和只读背包；仍是 ADVENTURE，不能旁观侦察 |
| 救援 | 站立托运者或投机客对倒地者空手按住使用；距离 <=2.5 格、LOS，连续 100 tick（5 秒） |
| 并行规则 | 一个救援者一次只救一人；同一倒地者只允许一名救援者占用，不叠加速度 |
| 中断 | 松手、距离/视线失效、救援者被有效攻击/推控、任一离线、倒地者流血到期、结算；进度清零 |
| 救起 | 进入 WOUNDED；原地站起；120 tick（6 秒）受击保护；首次主动采集/提交/攻击/用卡/交易即提前解除保护 |
| 补刀 | 截流器对 DOWNED 无效，不能缩短流血或刷包；靠守位截击救援者，而非处决连点 |
| 最终淘汰 | 一次性掉落剩余模式卡/未绑定包；绑定包和已 OFFERED 按04的终态规则处理；注销交易、清除模式属性；标准死亡转旁观并记录一次淘汰 |

倒地位置必须可落脚。非强制环境致命事件先将玩家移到上次合法安全点，再按首次倒地/再次淘汰路由；不在虚空、水底生成待救点。安全点每 20 tick 更新，只接受地面可站立、在地图内且不在门体/撤离检测区的位置；初值为出生点。

### 2.4 托运者推挡、狼受控

托运者 G 使用 `RoleSkill` 固有技能：准星方向 2.5 格内、LOS 的首名截流者受控 25 tick（1.25 秒），禁止移动/攻击/迟滞；自身冷却 500 tick（25 秒），成功施加才扣冷却。不造成伤害或击退穿墙。狼每次受控后获得 160 tick（8 秒）控制抗性，期间新推挡返回 `CONTROL_IMMUNE` 且不扣冷却；双人不能无限接控。卡牌若施加控制，也走这条统一抗性。

狼不通过正常战斗淘汰。外部普通致命事件把狼送回狼出生安全点、受控 60 tick，并施加 200 tick 同类环境复位保护；不刷包、不加击杀。管理员强制死亡仍执行最终淘汰；全狼失效按 01 中止。

### 2.5 强制死亡与效果清理

`forceDeath=true` 尊重管理员语义，直接最终淘汰，不进入首次倒地。模式内淘汰转交基类时使用内部“最终淘汰”作用域，避免再次拦截；该作用域不是暴露给客户端的布尔值。

模式速度、禁用、追踪和控制用独立来源 ID；结束时只撤销本模式的修饰，不使用“清所有药效”去误删其它系统状态。客户端禁键只负责表现，所有动作仍由服务端状态校验。最终旁观聊天/语音沿用 SRE 死亡隔离；退场/撤离也必须加入相同旁观语音隔离，不能留在活人语音频道。

## 3. 掉线、迟到、退出

- 正式阶段掉线即取消引导与交易，普通/黑晶和钥匙在最后合法点掉落；六格私有库存和契约转入运行态托管，不能同时留一份可操作 RoleData。
- 宽限 600 模式 tick（30 秒），主计时照常。记录位置与生命状态；若原本倒地，其流血时限仍推进，不以重连重置。每局每人只有一次宽限，第二次掉线直接按宽限过期处理。
- 重连核对 UUID、matchId 与本人托管状态，重建 RoleData 后移交私有状态并删托管副本；回到记录点，无新保护、无初始包；若该点失效回本人出生点，不允许主动选点。
- 到期未回视为退出：托运者不再计入 `stillPossible`，投机客的存活型契约失败，未锁定契约不再推进；已锁定成功保留。剩余包/卡落在最后合法点，一次且仅一次。
- 截流者宽限中仍被视为可能回归；所有狼都宽限过期/被强制淘汰则中止。中途新来的 UUID 只能旁观，不能捡资源或替补。
- 玩家主动退出参与或切换旁观直接过期，不再享受宽限。跨维度、非法传送也按退出处理；正常地图偏移迁移由模式内部受控流程处理。
- 断线不是获得隐身特权：没有离线替身或自动行动；不能在宽限期间守信标、阻挡、发信号或完成存活契约。

## 4. 四种个人暗牌

契约在 SAFE 发给本人并同步 HUD；开局抽取前校验地图是否存在所需点位。12 人无放回抽两个不同契约；契约本局不重抽。只读事件事实推进，不由客户端提交“我完成了”。

| ID / 名称 | 任务步骤与成功条件 | 暴露与失败边界 |
|---|---|---|
| `smuggler` / 走私商 | 从开放区黑晶点按住 4 秒采集；独立货槽最多两枚，与普通晶体槽共用容量；在本人指定投放点每枚引导 2 秒，累计提交两枚即锁定成功 | 黑晶搬运同普通货物减速；每次提交有 48 格可听的独特回声；倒地掉货、他人不能捡但 30 秒后回到黑晶点；死亡前已锁定则仍胜 |
| `information_dealer` / 情报贩子 | 两次真实双向非空交易，至少一次对手是真托运者，一次是真截流者；首次合格阵营各记一格，二格齐即成功 | 交易成功只提示双方，附近 16 格成交声；与同一玩家返还同一实例不再记；空换、单向赠送、管理员生成交易、同中立互换不记 |
| `scavenger` / 拾荒者 | 本人完成三次不同 packId 的选卡，并在正常主局结束时有效存活 | 三包达成时进入 ARMED，狼在 32 格内可见微光，每 15 秒一次；成功必须在线且 HEALTHY/WOUNDED，DOWNED/ELIMINATED/退出均失败；不能提前退场 |
| `key_dealer` / 钥匙贩子 | 经真实交易把钥匙交给托运者，并由该托运者成功消费该实例开核心门，使用时锁定成功 | 成交生成不可伪造来源记录；换人转手、丢地捡起、合成、偷取会使这条受让链失效，必须重新合格交易；使用时狼收到 48 格内增强钥匙脉冲 |

黑晶点初始两枚、耗尽后 60 秒补充，投放点不在锁门后；详见 09。拾荒者地图供应量有确定性下限，见 04；不能把“采集小概率掉包”当其可达性证明。

钥匙贩子只追最后一条有效的“本人→最终使用托运者”交易记录，`instanceId + tradeId + recipientUuid + consumed=false` 唯一；同一钥匙不能给多个中立重复计分。交易对手的真实阵营仅用于内部判定，交易面板不显示服务端真实阵营字段。

### 契约状态机

```text
ACTIVE → SUCCEEDED（即时型三个契约，事实锁定）
ACTIVE → ARMED → SUCCEEDED / FAILED（拾荒者，仅正常终局判定）
ACTIVE → FAILED（永久离场且未达成；或正常终局未完成）
任意 → VOID（主局中止，不记正式胜负）
```

成功即时型中立可以继续行动，也可在开放区 `brokerExit` 站定 3 秒后确认退场。退场不可逆，清掉/掉落其全部模式资源，不向托运者 Q 加一；其后只能旁观。留场不会解锁伤害权限。成功提示只给本人，公开信号按表发，不全图公告其契约名称。

## 5. 联合结算真值表

| 主局结果 | 玩家身份/个人事实 | `hasWin` | 单独展示 |
|---|---|---|---|
| 托运者胜 | 任一托运者（含淘汰/离线退出者） | true | 是否本人撤离、提交/救援贡献；不额外罚牺牲者 |
| 截流者胜 | 任一截流者 | true | 击倒、淘汰、迟滞、过载使用者 |
| 托运者胜 / 截流者胜 | 已成功的投机客（含已退场、后来死亡） | true | 独立契约完成时间和任务 |
| 托运者胜 / 截流者胜 | 拾荒者三包且终局在线站立存活 | true | 存活型契约 |
| 正常主局结束 | 对立主阵营 / 任务失败投机客 | false | 失败原因 |
| 管理员中止 / 无狼 / 重启 | 所有人 | 不计胜负 | `VOID`，保留日志但不污染战绩 |

SRE 标准 `wasDead` 仅反映旁观状态，已撤离者也可能是旁观；模式结果必须另存 `finalLifeState`，不能把“旁观”自动解释成淘汰。战绩、回放、结果屏均读取同一冻结快照。离线结果先按 UUID 进入模式结算记录，不在一次在线遍历中伪装成已成功更新所有统计。

## 6. 验收用例

- 同时两狼命中健康目标：首个倒地后第二个不触发淘汰；不多发两次包。
- 第 900 tick 救援未完成则流血淘汰；同 tick 完成救援只在截止前仍合法时成功，按 01 顺序不复活已淘汰者。
- 满包倒地：钥匙掉落释放原槽，普通卡仍在；救起无凭空复制。
- 推挡遇控制抗性不扣技能冷却；连续两次命中受创者保护期内不淘汰。
- 强制死亡不消耗“首次机会”来逃脱；普通环境死亡不把倒地者留在虚空。
- 拾荒者只开完未选卡不算次数；三包后倒地到终局不胜；即时契约成功后死亡仍胜。
- 重连不刷初始包、不刷新候选、不洗掉受创；第二次掉线不再给 30 秒。
- 两种主胜中都能出现中立共同胜者，且不提前停主局。
