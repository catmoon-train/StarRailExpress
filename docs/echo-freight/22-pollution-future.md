# 22 · 污染机制（已下线，留作 future）

> 状态：**当前版本不包含污染机制**。本文只记录它原本是什么、为什么下线、以及将来若要恢复需要满足的前提。
> 现行规则以 [01](01-gameplay.md) 的胜负与阶段、以及各系统的「现行」段落为准。

## 1. 为什么下线

污染原本是截流者唯一能直接打击托运者进度的能力，代价是它把一座信标的状态拆成 **4 个互相独立的计时器**：

| 计时器 | 原默认 | 作用 |
|---|---|---|
| `lockedUntil` 封锁 | 20 秒 | 充能不推进，也不能再次污染 |
| `pausedUntil` 暂停 | 5 秒 | 充能不推进，但仍可提交 |
| `nextPolluteAt` 污染冷却 | 45 秒 | 该信标全狼共享的下次可污染时间 |
| `stableLayer` 稳定层 | 1 层 | 挡一次回退，不挡封锁 |

再加上「回退 20%/40%」「净化器解封但不回补」「稳定剂挡回退不挡封锁」「净化稳定剂先解封再附层」等组合，玩家要同时记住 4 个数字、3 种反制卡和 2 张狼卡，才能判断「这座信标现在能不能推进」。这是全模式里认知成本最高、收益最不直观的一块。

## 2. 替换成了什么

截流者现在用 **迟滞（stall）** 控制节奏：

- 对一座**正在充能**的信标引导 20 秒（破坏者专长按 `stallSpeed` 缩短）；
- 成功后退迟滞 **20 秒**（强迟滞卡 45 秒）；
- **进度永不倒退**，只是这段时间不再增长；
- 同一时刻只有一段迟滞，重复施加无效。

托运者侧的对应反制是「稳流阀（清迟滞）」与「信标助推 / 信标超载（直接推进进度）」，全部只操作一个 `stalledUntil` 字段。

## 3. 原机制存档（如需恢复）

原始实现要点，仅供将来参考：

```text
污染成功（仅作业期、满料、未 ACTIVE、未封锁、过冷却）：
  1. 消耗攻击者"下次污染"标记（仅成功才扣）
  2. 有稳定层 → 消耗一层，本次回退变 0；封锁仍生效
  3. 否则 progress -= 20%（强污染 40%）
  4. lockedUntil = now + 400 tick（20 秒）
  5. nextPolluteAt = now + 900 tick（45 秒，全狼共享）
  6. 发污染信号；首次污染该信标者得黑市包（全局每信标一次）
```

原卡池中与污染绑定的 4 张卡：`pollution_accelerator` 污染加速、`strong_pollution` 强污染、`overload_pulse` 过载脉冲、`purifier` 净化器；`stabilizer` 稳定剂与 `purge_stabilizer` 净化稳定剂是它的反制。

## 4. 恢复前提

如果将来要重新引入，必须先满足：

1. 信标 HUD 能同时显示「回退损失」「封锁剩余」「暂停剩余」三段时间，而不是现在的单行 `锁/停/稳`；
2. 卡面描述读取本局冻结规则的实际秒数，不写死默认值；
3. 有对应的纯状态测试覆盖：回退、封锁与暂停叠加、净化不解冷却、稳定层只挡回退；
4. 至少一次真实多人验收，确认玩家能在 3 秒内看懂当前信标能不能推进。

在此之前，保持现在的单一迟滞计时器。
