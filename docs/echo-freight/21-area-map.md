# 21 · 常驻区域地图与设施标记

## 使用

回声托运站活动对局期间，无需持有地图物品，右侧常驻北向小地图。以自己为中心显示72格视野、地形切片、朝向与本局固定设施；打开背包或其他窗口时让出界面，F1隐藏HUD仍有效。

复用现有投票绑定（默认 M）：回声对局中打开区域大地图，再按同一键或 ESC 关闭；实际会议/地图投票仍优先，普通模式的投票操作不变。用户重新绑定此键后，地图入口和提示同步使用新绑定，不动态注册按键。

大地图首次适配整个区域，左键拖动平移、滚轮缩放、可切换2D/3D；3D视图右键拖动旋转。右侧图例按本局设施类型筛选，与小地图共享；悬停查看设施名称、编号和高度坐标。白点为自己，金点为朝向。

## 点位来源与隐私

`EchoFacilityMapSnapshot` 从已转换为实战坐标的本局 `EchoMapConfig` 生成快照，按开局人数阈值过滤，包含普通/核心信标、晶体采集器、钥匙祭坛、物资箱、黑市、核心控制台、免费出口、撤离控制台和撤离区域中心、黑晶采集/投递及投机客退场点。

各阵营收到同一份公开固定点位。不包含出生点、旁观点、安全落点、敌我玩家、掉落物、私人契约或箱子实时冷却；地图标记不是服务器目标状态的第二份可写副本。撤离区域中心复用撤离控制台类别的第2号点，悬停以“撤离区域”区分。

每局点位仅构建一次，观察者加入、重连、换局和维度切换发送完整快照；服务端40tick保活，客户端200tick过期。结束发送空快照；客户端还校验世界实例、维度、对局ID和活动模式，避免沿用旧图。设施筛选每局恢复全选。

地形继续由现有 `AreaMapManager` 从客户端已加载区块限量扫描（800列/tick、500ms上传节流），不强制加载区块。远处未加载地形允许留空，配置设施仍可在大地图定位。进入回声模式即开始扫描，不再等待手持地图。

## 布局与检查

右侧小地图边长86–110逻辑像素，下方两行狩猎状态不覆盖底部信息和快捷栏；320×240逻辑分辨率也可用。地图绘制使用 `FakeGuiGraphics` 缓存，避免只在脏帧出现；大地图使用实时屏幕绘制。

回归包含设施人数阈值、类型覆盖、坐标只平移一次、协议不可变/有界与敏感点位排除、M键/扫描接线及三语占位符。`EchoUiGeometryCheck` 覆盖小地图与HUD边界。游戏内缩放、地图切片、多人重连与实际视觉仍需实机验收。
