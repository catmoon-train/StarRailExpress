# 25 · 经济系统与修机小游戏

> 现行规则。参考 `docs/repair-mode-reference.zip` 的校准条与金币商店，但按本模式的资源与胜负重做：
> 货币复用仓库已有的金币钱包，抽卡仍走原来的三选一，不新增第二套抽取算法。

## 1. 货币

- 复用 `PlayerSkinEconomyManager`（仓库既有的金币钱包），**跨对局、跨模式保留**；本模式只定义「怎么赚、在哪花」。
- 所有金额是整数，不做小数、不做按比例分成。
- 同一事件按去重键只结算一次，避免反复触发刷币。

### 1.1 收入来源

| 来源 | 金额 | 去重键 |
|---|---:|---|
| 完成一次修机采集 | 6 | 不去重（每次采集都算） |
| 首次向某座信标提交 | 12 | 信标 id |
| 首次迟滞某座信标（追捕方） | 15 | 信标 id |
| 首次击倒某名逃脱者 | 20 | 受害者 UUID |
| 完成一次救援 | 18 | 被救者 UUID |
| 完成一次真实交易 | 10 | tradeId（双方各得一次） |
| 个人契约锁定成功 | 40 | 不去重（每人每契约一次） |
| 成功撤离 | 30 | 不去重 |

## 2. 卡包商店

商店分两页：**道具卡包**与**技能卡包**。两页都只是把现有的三档物资包（普通 / 稀有 / 黑市）包装成商品，
买到手的是一个物资包，抽卡仍然走原来的三选一。

| 商品 | 分类 | 品质 | 价格 |
|---|---|---|---:|
| 道具卡包 · 普通 | ITEM | 普通 | 20 |
| 道具卡包 · 稀有 | ITEM | 稀有 | 45 |
| 道具卡包 · 黑市 | ITEM | 黑市 | 80 |
| 技能卡包 · 普通 | SKILL | 普通 | 25 |
| 技能卡包 · 稀有 | SKILL | 稀有 | 50 |
| 技能卡包 · 黑市 | SKILL | 黑市 | 90 |

- 技能包整体比同档道具包贵 5–10 币：主动技能卡在单局里的即时收益更高。
- 购买失败（余额不足、不在可购买阶段、限频）**不扣款**。
- 买到手的包进六格背包；满包按既有规则落地。

## 3. 售货机

对局中右键售货机直接打开回响商店的售货机页，不再走普通职业商店。

| 商品 | 价格 | 效果 |
|---|---:|---|
| 治疗包 | 30 | 立刻回复 3 点生命（倒地时不能使用） |
| 兴奋剂 | 25 | 2 秒 ×1.20 移动加速 |
| 信标助推卡 | 40 | 直接拿到一张「信标助推」，省去抽卡 |
| 稳流阀卡 | 40 | 直接拿到一张「稳流阀」，用来清除迟滞 |
| 稀有物资包 | 55 | 直接拿到一个稀有品质物资包 |

**限购规则**：每名玩家、每台售货机、每件商品**只能买一次**。售出后按钮显示「已售出」但仍可见，
避免玩家以为商品消失。去重键是 `机器坐标 | 商品 id | 玩家 UUID`，只保存在本局会话里，跨局自然清空。

**交付回滚**：先登记售出、再交付；交付失败时撤销售出并退款，保证不会「扣了钱没东西」。

## 4. 修机小游戏（圆环指针）

采集晶体不再是「按住 4 秒」，而是先打一轮校准判定。

### 4.1 流程

```text
按住右键对准晶簇 → 服务端开一轮判定 → 客户端弹出圆环界面
  → 指针沿圆周旋转；进入绿色弧段时按空格 / 左键
  → 服务端按自己的 tick 重算指针位置并判定
      HIT   → 产出晶体（原有采集奖励照常）
      MISS  → 不产出，节点不进入恢复，可以立刻重试
      DESYNC→ 客户端上报与服务端不一致，判失败
      EXPIRED→ 400 tick 内没按，自动失败
```

### 4.2 数值

| 参数 | 值 |
|---|---|
| 圆环刻度 | 1000（一整圈） |
| 正常转速 | 18 刻度/tick（约 2.8 秒一圈） |
| 失控转速 | ×2.1（约 1.3 秒一圈） |
| 正常判定区 | 120 刻度（约 43°） |
| 失控判定区 | 70 刻度（约 25°） |
| 基础失控概率 | 12% |
| 客户端容差 | 60 刻度（超过判 DESYNC） |
| 单轮超时 | 400 tick（20 秒） |

**失控**：每轮开始时有 12% 概率进入失控——指针更快、判定区更窄，并在界面上用红色标题与琥珀色弧段提示。

### 4.3 职业与卡牌影响

| 来源 | 影响 |
|---|---|
| 搬运工 `hauler` | 判定区 +8 刻度；失控概率减半（6%） |
| 速取 `swift_pick` | 下一次采集瞬发，跳过判定 |
| 静默采集器 | 判定命中后压制本次声光，不影响判定本身 |

### 4.4 采集故障声纹

判定失败（`MISS` / `DESYNC` / `EXPIRED`）时，服务端向 **48 格内的站立追捕者**各发一次
`fault_pulse` 方向信号：只给扇区，不带坐标与 UUID。追捕者 HUD 上以**红色**显示
「采集故障（红圈） · 方向」，方便循声找人。

### 4.5 防作弊

- 客户端只上报「按下时的指针位置」，服务端**按自己的 tick 重算**权威位置。
- 两者偏差超过 60 刻度直接判 `DESYNC`，不给奖励。
- 客户端不能指定判定区、转速、概率或结果。
- 同一玩家同时只允许一轮未完成判定；断线、倒地、离开模式会清掉。
