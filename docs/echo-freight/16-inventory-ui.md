# 16 · 原生背包与 3＋6 快捷栏

本次 UI 调整覆盖 04/08 中旧的“托运背包入口按钮、独立 EchoInventoryScreen、只显示三格快捷栏”设计，库存事务与资源台账规则不变。

## 入口与布局

- 背包键直接打开 `LimitedInventoryScreen` 的回声布局，内部由 `EchoInventoryPanel` 管理组件；不再增加“托运背包”按钮或独立背包屏幕。
- `/sre:echo_bag` 只是打开同一个原生背包的兼容别名。
- 原生背包顶部显示身份、阶段、货物和钥匙；中部查看物资详情并拆包、使用、合成或丢弃；交易、契约、专长沿用其专门页面，返回原背包。
- 底部和游戏内快捷栏均分成“固定工具 3 格｜随身物资 6 格”，总计九格；后六格不是另一份库存。

## 操作

- 第 1–3 格：阵营工具/空手交互、卡牌终端、专长信物。可选择但不可移动或交换，包括空的工具格。
- 第 4–9 格：唯一六格资源库存的对应快捷栏位置。数字键或滚轮可选择，主动卡可直接右键使用，不必先装备到终端。
- 快捷栏持物资包右键，立即提交拆包请求并打开同一原生背包显示引导和三选一，无需再点“拆开”；已有引导/候选时只恢复原流程。被动卡、阵营不符、锁定及无目标会给出明确提示。
- 背包内单击查看一件物资；Shift+单击第二张卡预览同系列基础卡合成；合成需确认。
- 选中一件物资后点击空物资格，发送服务器 MOVE 事务；不拿原版鼠标栈搬运资源。
- 同格两个物资包可用左键/右键分别选第一/第二个实例。
- 三选一在原背包同屏展示；每张说明单独滚动，按钮与倒计时始终保留。关界面不会重抽候选；尚在引导时关闭会取消拆包。
- 丢弃通过服务器事务并明确确认；交易锁、选卡保留和服务器等待状态持续显示。

## 一致性与验证

快捷栏 ItemStack 只作展示和输入，资源实例、消耗、合成及交易仍由服务器台账与 revision 决定；普通原版容器点击不能拿走、复制或交换投影与固定工具。

`EchoInventoryLayoutTest` 覆盖 320×240 至 1920×1080 逻辑尺寸下的分组间距、槽位边界、详情区/操作区/页脚及三选一区域。真实游戏还应确认缩放、右键用卡、三选一、合成/交易与重连的交互效果；几何测试不等于实际截图验收。
