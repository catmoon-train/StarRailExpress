# 18 · 逃脱者翻滚与共享出生点

## 翻滚

托运者（逃脱方 `CARRIER`）新增独立的 **30 秒**翻滚冷却：按住玩家已绑定的潜行键，再按职业技能键
（默认 `Shift+G`）。不按潜行时仍是原来的 G 推挡，专长信物的技能不变；不新增按键或物品。
右下信息栏显示组合键与翻滚剩余冷却。

参考 `G:/download/CombatRoll-1.21.1` 的地面翻滚机制：8 tick 收身翻滚、约 3 格地面速度冲量、
按移动方向选向，无方向输入时向前，冰面作速度补偿。实现独立使用本项目现有 Fabric / Minecraft API，
不增加 CombatRoll 或动画库依赖，也没有复制其动画资源。

服务器重新校验本人会话、阵营、阶段、存活、控制、冷却、地面、载具、使用物品、液体、
地图边界及已加载区块；客户端请求不能决定距离、速度、冷却或时长。
失败不扣冷却，成功取消原来的采集/提交引导并打断救援保护。
位移使用原版速度和碰撞，不连续传送、不缩小碰撞箱，**不新增无敌帧**。
翻滚中禁止额外移动加速与跳跃，服务器不接受其它资源动作；第三人称完整翻身、屈膝收臂，
第一人称只压低手部，不旋转相机。

冷却由会话持有，按比赛 tick 推进：暂停冻结，断线和重连不返还；倒地、受控、切换维度、
离开会话或结算会取消动作。退出不把翻滚速度或人物姿势留给普通模式。
F1 隐藏 HUD 不影响技能及输入约束。

## 中立共用出生池

用户确认的是 **共用出生点池**，不是淘汰后重生。
投机客（中立 `BROKER`）与托运者开局共同按顺序使用 `carrierSpawns`，到池尾循环。
重连仍先恢复上次安全位置，需要回出生点时也回到从这个共享池分配的位置。
旧地图的 `brokerSpawns` 保留读取兼容，但不再用于出生、路线和安全检查，缺省也不阻止开局。
原来的倒地、救援、二次命中淘汰与旁观规则不变。
