# 布袋鬼第二轮重做：已确认规格

> 用户逐项确认后要求实现。本文件记录最终取舍；旧 `sack-ghost-guest-rework-proposal.md` 是上一轮基线。本轮实现与验证状态以交付说明为准，不能把规格描述当成已经完成的验收。

## 1. 保留范围与共同规则

- 保留四阶段成长门槛、实际削 SAN 计数、被动侵蚀、普通魂噬、真实阵营判定与诡客法器机制。
- 保留随机抽取、原有开局两件、四件持有上限、归属和一次性 token 防复制规则；隐身第一阶段加入随机池，不开局额外赠送，随机抽取仍允许重复类型。
- 抽取冷却为 `max(10, 55 - 开局参战人数)` 秒，人数整局固定。
- 所有物品诡术共用 10 秒成功施法冷却，非各自独立。失败不消耗、不进入冷却。
- 常态消耗一次性诡物，里世界使用已持有诡物不消耗，但仍受共用冷却限制。
- 隐身物品始终不消耗，有独立 65 秒冷却，同时受共用 10 秒冷却限制。
- 回响第二段属于后续操作，豁免共用冷却且不重新触发共用冷却。
- 使用既有按键、RoleData、生命周期与粒子批量接口；保留无关工作区改动与版本号。

## 2. 被动替死

- 开局一次、最多储存一次，消耗后 150 秒恢复。
- 致命攻击在正常护盾结算后触发替死。
- **原地**化为独立鬼影，不进行任何自动位移或向前传送。
- 鬼影持续 12 秒，速度 III、全程无敌；不能攻击、使用诡术或开启里世界。
- 替死同样保护离体期间的本体；本体触发替死时先中断里世界并回到本体，再原地进入这段鬼影保护，不提前处决旧标记者。

## 3. 里世界本体与回归

- 开启后留下一具使用本人外观的可攻击本体，玩家操控独立厉鬼鬼影出动。
- 施法点 6 格内寻找最近空床，不隔墙找床。有床自动躺上；无可用床原地躺下。
- 本体遭有效攻击，直接尝试致死，不只是打断里世界；正常护盾可抵挡，替死也可救。
- 结束时回到本体，从床上或地上起身，立即恢复操作。
- 床被破坏不删除本体，改为留在原处躺卧；位置失效时做安全回归。
- 三阶段近战每次削 **50 SAN**，四阶段 **70 SAN**。
- 其余里世界规则不变：三阶段解锁、原时长及 120 秒冷却、开场压制、全图侵蚀与周期透视、原命中间隔、归零命中登记标记、自然结束处死、中断取消及法器反制。

## 4. 枪械预警

- 半径 15 格、全方向、可隔墙；对象为非杀手阵营，包含非杀手中立，排除杀手及杀手方中立。
- 常态以自身为中心，有人携枪提示 **周围的好人对你产生了威胁**，手持枪械额外显示大红 **危**。
- 鬼影出动期间**只检测本体**周围，不检测鬼影。
- 离体携枪提示 **本体附近有人携带枪械**，手持改为 **本体附近有人手持枪械**，同时显示大红 **危**。
- 不显示威胁玩家名字或距离。

| 1 | 鬼遮眼／鬼手蒙眼 | 施法12格，落点半径5格，削32 SAN；蒙眼、禁止攻击与使用物品3秒。仍能移动、使用职业技能。 |
| 1 | 推走／鬼潮震退 | 自身半径7格，削20 SAN，向外最多击退9格；遇墙停止、不穿墙。 |

| 2 | 替身草人／活化追猎 | 存在30秒，索敌15格，追逐最近敌人，略快于普通玩家疾跑；最多一个。扑中削35 SAN、定身2秒，随后消散。 |

| 4 | 夺魄／鬼手拘魂 | 取消低SAN门槛。15格视线内，将目标快速拖到身前约2格，削30 SAN，抵达后定身2秒。不是简单瞬移，不穿墙；路径或落点不安全失败且不消耗。没有新增直接处决。 |

## 6. 视觉验收

- 两种鬼影状态都使用**独立厉鬼形态**：裂布袋罩头、猩红鬼眼、细长身形、拖曳破布与黑影、扭曲残影。普通玩家变透明或只加烟雾不算完成。
- 鬼遮眼：受害者画面两侧鬼手合拢蒙眼。
- 推走：巨大地面鬼面骤现，环形阴风夹鬼影向外爆开。
- 草人：本人外观追猎，接近目标时假身扭曲、裂开露出鬼影扑击。
- 回响：可见残影与回归爆裂。
- 怨声：鬼影张口尖啸、暗色音浪持续扩散。
- 寄生：贴背恶灵随SAN降低逐渐显形、收紧。
- 夺魄：巨大鬼手扣住目标并拖回。
- 按粒子设置、距离与有界时长清理表现，避免服务器逐颗粒子发包；断线、换世界、死亡、局末清理。

## 7. 并行实现接口

以下接口供本轮分工对接，数值与行为仍以上文为准。

### 服务端公开同步

`SackGhostPackets.FormS2C(UUID owner, int flags, int remaining)`：位1=里世界鬼影，位2=替死鬼影，位4=隐身；0清理。`VeilS2C(int remaining)`：仅发受害者，0撤销蒙眼。现有 `RealmS2C` 保留法器与里世界计时。

本人 `MaChenXuRoleData` 新同步字段：`escapeCooldown`, `escapeTicks`, `shroudCooldown`, `shroudTicks`, `echoTicks`, `threat`（0/1/2=无/携枪/手持），`bodyThreat`（离体预警）。

客户端特效 id 统一为 `noellesroles:sack_ghost/<name>`，name：`veil`, `push`, `effigy`, `echo_depart`, `echo_return`, `wail`, `parasite`, `seize`, `escape`, `realm_depart`, `realm_return`。使用 `ParticleFx.sendCustom`，参数为可选目标实体id等（最多8个float）。

### 实体对接

`SackGhostActors` 提供 `createBody(ServerPlayer)`, `tickBody(Body)`, `restoreBody(ServerPlayer, Body)`, `removeBody(Body)`, `spawnEffigy(ServerPlayer, Vec3)`。Body提供 `entity()`, `position()`, `level()`。

本体有效受击转发 `MaChenXuRoleData.onBodyHit(PuppeteerBodyEntity, DamageSource)`；不直接强杀或擅自丢弃本体。草人扑击转发 `onEffigyHit(ServerPlayer)`。实体用 `combatClockRunning()` 判断暂停。

物品约定：`GhostArt.SHROUD("shroud", 1)`；`ModItems.GHOST_ART_SHROUD`；资源 id `ghost_art_shroud`。
