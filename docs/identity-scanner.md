# 身份扫描仪

## 固定终端

- 注册ID：`noellesroles:identity_scanner`，方块/场景分页，固定地图设施，生存不可破坏。
- 右键只打开终端，不收费。非中立阵营玩家（含旁观者）可查看本机公开历史；中立阵营不能打开或操作终端，执行付费扫描仍仅限存活且能使用物品的玩家。
- 点击扫描花费50金币，随机公开一名当前仍然死亡的本局玩家：真实姓名和死亡时职业。每名使用者本局按死者UUID去重，跨机器共享；其他使用者的个人候选池相互独立。
- 每台机器独立冷却30秒，多人共用这台机器的冷却。无候选、金币不足、冷却中或非法请求不扣费、不添加历史。
- 历史与机器冷却保存到方块实体，区块卸载不重置；新一局重置。每台保留最近256条，所有访问者看到相同内容，打开期间每秒刷新。
- 服务端检查打开上下文、维度、方块类型、已加载区块、6格距离及请求频率；客户端按钮不具有交易权限。
- 随机池来自真实死亡事件，不要求尸体仍存在。复活者暂时排除，离线死者保留；再次死亡更新身份，但不会重新进入已扫描者的个人候选池。

## 随身扫描仪

- 注册ID：`noellesroles:portable_identity_scanner`，工具分页；验尸官商店可花125金币购买，使用免费且不消耗，中立阵营不可使用。
- 手持右键瞄准5格内无遮挡的真实尸体，主标题显示死亡时职业（沿用职业颜色），副标题显示死者姓名，只有使用者可见，不再依赖聊天栏。排除伪造尸体、伪装活人及已复活者的旧尸体；冷却和无效目标提示改用屏幕下方提示。
- 成功后使用者冷却120秒，同类物品共享此人的冷却，换物品不能绕过。无效目标不启动冷却。
- 随身结果不写公共终端，不占随机终端的个人去重名额。
- 扫描仪可以丢弃，主副手与第一/第三人称手持时隐藏，但背包图标和地面掉落物仍正常显示。
- 验尸官从开局或本局首次成为该职业时开始，前150秒不能丢弃扫描仪。此期限按玩家每局只登记一次，与是否持有、购买或扫描无关；到期后再买、捡回、重连或再次变为验尸官不重新计时。其他职业不附加此限制；限制期间的尝试会显示剩余秒数。
- 使用局内游戏时钟计算权威扫描冷却和首次丢弃期限，暂停时均不走表。RoleData只向本人同步期限，客户端按同一时钟预测按键，服务端复核；只在期限首次登记或变化时同步，不逐tick发包。局末/新局/世界卸载/停服清理单局账本，不在玩家离线时删除去重和冷却。
