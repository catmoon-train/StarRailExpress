# 回声地图编辑仪：一键识别机器

放下 12 种回声机器**不会**自动成为玩法点位。编辑仪可以按准星上的机器外壳写入草稿点位，但仍须到「保存检查」页保存。

## 怎么用

1. 先在编辑仪里新建或载入地图配置（需要 OP2，且不在对局中）。
2. **潜行 + 右键**对准 16 格内已加载的机器：服务端按当前视线识别并标记。普通右键对着空气或方块仍打开编辑界面。
3. 界面「点位坐标」页也有 **「识别当前机器」**。界面打开时客户端准星可能冻结，所以服务端会重新取玩家最新视线，不采用按钮按下时的旧坐标。
4. ID 框、人数框可以预先手填。ID 留空则自动生成不冲突的 id（如 `crystal_1`）。人数留空默认 6，只对信标、晶簇、物资箱、黑市箱生效。
5. 再次识别同一方块会更新既有点位，不会再堆一条。手填的 id 若已被另一坐标占用，会拒绝而不是覆盖。
6. 准星不是这 12 种机器时，会明确提示失败，不写入草稿。
7. 识别结果只在内存草稿里。反馈会写明类型、id、坐标，并说明**尚未保存**。

手动标记非机器点位（出生点、安全点等）和区域框选保持原样。

## 机器与点位

| 机器 | 点位 kind |
|---|---|
| 开放信标 | `beacon_open` |
| 核心信标 | `beacon_core` |
| 晶簇采集机 | `crystal` |
| 钥匙祭坛 | `altar` |
| 物资箱 | `supply` |
| 黑市箱 | `black_market` |
| 黑晶采集机 | `black_node` |
| 黑晶投放机 | `black_dropoff` |
| 核心门控制台 | `core_control` |
| 安全出口终端 | `free_control` |
| 撤离控制终端 | `evacuation_control` |
| 投机客退场终端 | `broker_exit` |

类型与坐标只由服务端 `EchoMachines.kind(BlockState)` 和 16 格射线决定，客户端不能指定。
