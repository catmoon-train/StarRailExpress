# 克隆博士

普通杀手职业 `noellesroles:clone_doctor`，固有修饰符 `noellesroles:cloned_person`（克隆之人）。修饰符不进入随机池，也不开放刷新配置；通过职业初始化/分配修饰符补齐。

## 已确认规则

- 技能1使用原技能键：服务端检查16格视线内的存活非中立玩家，目标职业必须允许被其他职业随机到。1秒有声音的前摇结束时复核目标、职业、距离和视线；中断不消耗冷却。
- 成功后复制职业60秒，恢复克隆博士后开始30秒冷却，自动到期和提前返回均给满30秒。只变能力职业，不复制目标皮肤，实际阵营始终是杀手。10秒隐身并禁止造成伤害（不额外免伤）。背包按钮可提前返回，复制职业技能键保持原样。
- 临时初始化的是博士自己的目标职业数据，不复制或共享目标玩家的RoleData。正常派发职业移除/赋予事件。跨职业会话独立保存，避免返回计时随博士RoleData销毁。
- 初始化时隔离背包和余额，临时初始物品带所有者及本次会话UUID；背包满时暂存，出现空位再发。返回回收临时物品，保留原物品的正常使用、耐久损耗、拾取和金币收支。临时物品不能丢弃转交、存入容器或扩展槽。
- 不把临时切换计入正式转职成长统计，不重置一局限次任务奖励。复制平民（不含警长）时每次任务35金币，不叠加默认金币、连击或同步职业金币奖励；原任务能力仍执行。
- 技能2在博士背包中点击存活杀手队友头像（包括自己）。每次100金币、500秒冷却，成功创建后才扣费/计时。每个目标最多一个有效替身。
- 使用目标开局分配的房间坐标。床按最近房间坐标归属，在归属该房间的已索引床中找最近床头；无床在房间坐标生成横卧玩家傀儡。替身不占用真实床。
- 目标遭受游戏致命攻击时，普通盾、限时盾、弱效盾、疯狂盾及默认阶段的护盾后否决优先。之后才消耗替身，否决该次死亡并传送目标躺卧。强制死亡不消耗替身。替身自身可被攻击销毁，绝不转移伤害给目标。
- 替身保护不依赖制造者之后是否死亡或换职业；目标死亡/离线、房间失效、床损坏、局末、世界卸载会清理，区块票据同步释放。
- 商店：毒药60、开锁器80、范围关灯175、粘液弹50金币。粘液弹购买冷却120秒，不是使用冷却；背包最多一枚，服务端插入/拾取也校验。

## 代码边界

- `CloneDoctorRole`：职业、商店、技能定义和身份判断。
- `CloneDoctorSessionManager`：前摇、正常变职事务、返回、临时物品、跨职业冷却与同步。
- `CloneDoctorTimers`：可独立测试的期限规则，使用可暂停的局内tick。
- `CloneDoctorRoleSnapshot`：回收初始化引入的属性/效果，不全量清除其他修饰符或外部增益。
- `CloneSubstituteManager`：房间、床、傀儡、护盾后保护与清理。
- `CloneDoctorClient`：本人状态、倒计时和跨职业返回按钮；职业选人扩展复用现有分页搜索。
- 客户端初始化必须调用 `CloneDoctorClient.register()`，同时接通状态接收、背包返回按钮和HUD；注册入口自带防重复保护。克隆前摇在准星下显示进度条，并在动作栏显示目标姓名；返回按钮固定在屏幕底部居中，不再尝试顶部位置，避免遮挡修饰符说明。两个技能冷却归零时以绿色显示“已就绪”，冷却中显示剩余秒数。

## 实际阵营API

`SREGameWorldComponent.getRole/isRole`仍表示当前能力职业，保证旧职业逻辑和RoleData正常工作。

新增 `getAllegianceRole(Player/UUID)` 表示实际阵营身份：克隆返回博士，其他玩家返回当前职业。胜负、存活计数、玩家敌我关系和友杀判定使用此入口。需要玩家维度判断的调用方可用 `RoleTeam.matchesPlayer/ofPlayer`，不要仅拿能力职业的`canUseKiller/isInnocent`推断实际阵营。

阵营身份通过通用 `RoleAllegianceEvents.OVERRIDE` 扩展：克隆博士在自身初始化入口注册身份覆盖，核心查询不直接判断具体职业；无覆盖时才查询能力职业。Player 重载使用玩家所在世界，UUID 重载使用组件所在世界并支持离线身份，空参数返回 null。

## 验证范围

自动化测试覆盖前摇、恢复本体起算30秒冷却、提前返回、独立计时、暂停期限、翻译和替身接入约束。完整客户端/服务端联机仍需验证睡姿、各允许复制职业的特殊生命周期，以及盾后传送。

床搜索复用地图已有索引，不自动识别未进入索引的新放置床。无床躺卧由服务端维持，移动或潜行起身；视觉和命中盒需实机确认。任务额外金币抑制作用于同步回调，不拦截其他职业自行异步延迟入账或直接写公开余额字段的实现。

## 变身状态提示

- 变身期间独立HUD状态区持续显示当前能力职业名称和恢复本体剩余秒数，长职业名自动换行，倒计时随局内时间冻结。
- 自动到期、背包提前返回均在服务端恢复成功后发送3秒顶部SubtitleHUD报幕：“已恢复克隆博士”。死亡、断线和外部转职清理不误发返回提示。

## 平民复制时的结算与透视

- 两侧存活计数、双重计数死锁检查、存活阵营统计及玩家队友判断统一查询实际阵营，不能直接用当前能力职业判断。最后一名杀手博士复制平民后仍计入杀手侧，不会因此触发好人胜利。
- 有“克隆之人”标记的玩家，无论本体还是复制职业，已被直觉允许显示的轮廓统一为五秒循环彩虹色。最终着色保留空结果，不绕过原本的隐身/禁用/死亡惩罚限制；缓存命中时每帧重算颜色，不额外发包。
