# 布袋鬼加强：当前平衡规则

本轮用户确认的规则覆盖 `sack-ghost-rework-v2.md` 中对应旧数值；其余机制不变。

- 抽取间隔：`max(20, 50-N)` 秒，N仍采用固定开局参战人数。
- 取消共用施法冷却，改按诡术种类独立，同种多件共用该种冷却。隐身结束或提前解除后冷却30秒，其余诡术成功施放后冷却25秒，常态与里世界一致。失败不消耗、不进入冷却。
- 常态普通诡物成功使用后有50%概率消耗一件；隐身始终不消耗，里世界内使用诡物也不消耗。回响第一段成功时只判定一次概率，在返回、超时或中断时结算，返回不重启冷却。
- 所有削SAN相对当前实现提高30%；里世界内再额外提高25%，乘算为1.625倍。被动原有1.3倍侵蚀系数保留，因此相对原始基线，常态被动系数为1.69，里世界为2.1125。成长仍只统计实际SAN降幅。
- 常态诡术实际削SAN：鬼遮眼41.6，推走26，草人45.5，回响31.2，怨声每秒10.4、全程52，寄生每秒6.5、全程97.5，夺魄39。里世界内这些数值再乘1.25。
- 里世界近战第三／四阶段分别削81.25／113.75 SAN。中立及无真实SAN目标的虚拟血量伤害仍为10／14，不因削SAN加成而提高。
- 里世界鬼影获得速度VII；替死鬼影仍为速度III。
- 仅里世界期间，以操控中的鬼影为中心，半径15格（含边界）的敌人持续受到失明、颤抖与瘸腿I。队友不受影响，不需要视线。范围每5 tick刷新，离开范围、领域结束或中断时撤销本领域施加的效果，保留外部效果基线。
- 各诡术剩余冷却同步到客户端并独立显示；时间暂停不消耗冷却，回溯不会缩短已经触发的诡术冷却。

验证范围为本角色纯规则、生命周期接线测试及模组构建；多人联机和最终画面仍需游戏内验收。
