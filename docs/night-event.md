# 黑夜事件

## 玩家规则

- 黑夜是本局环境事件，不是可选择职业，不占杀手名额，也不改原有阵营或胜负判定。
- 默认不自然出现：`NoellesRolesConfig.nightEventEnableChance = 0`，单位万分比；人工需要时可改概率。
- 管理员（权限等级 2）执行 **`/sre:night next`**，为下一局可用对局排队。重复排队返回提示，不重复叠加。进行中的局（含安全时间）不因这条命令改变；结束当前局不丢失请求。不支持的模式或禁用事件时顺延，不消耗请求。请求不跨服务器重启保存。
- 支持与命令方块相同的谋杀派生模式；不支持躲猫猫、邪战、TNT、赌徒、发现、鹅鸭杀和非谋杀模式。
- 开局标题和聊天说明：持续关灯、视野最多 **16 格**、初始手电筒、死者变为亡灵。轮选 / 单选 / 志愿海选等先完成装备初始化再启用，不让选职业清掉手电筒。
- 灯在本局始终停电，修电和普通开灯不能解除；临时停电不再堆积新的倒计时。时间固定在午夜，退出后撤销本事件的时间和灯光改动。
- 所有玩家（包括旁观）使用球形世界雾，将最远可见距离限制在 **16 格**，不更改 FOV 或客户端渲染距离设置。复用视野迷雾管线，最后 2 格渐隐；已有更强的失明、液体、场景或效果雾仍然保留更短距离。F1、夜视与职业豁免都不能放宽这个上限。
- 参赛者每人初始获赠一把已点亮的现有手电筒，右键切换开关；满背包落在本人脚下并限定拾取人。重连不重复配发；普通旁观者不发装备。
- 真正死亡后，在死者位置生成使用其皮肤的独立黑夜亡灵，本人继续旁观，不能操控亡灵。不把护盾、替身等被阻止的死亡算成转化。同一死亡去重，真正复活后可再次转化。
- 黑夜亡灵不占亡灵之主名额、不依赖其存活、不注入其感染；沿用独立活动亡灵的接触近战伤害和安全期保护。寿命持续到被消灭或本局结束；冻结会暂停其行为。
- 与万圣节同开时，黑夜负责该次死亡的亡灵化，避免 NPC / 惊魂枪把同一死者重复转换。其他南瓜收益与道具机制保持。

## 亡灵通用调整

所有亡灵改为更透明的上半身外观（约 50% alpha），隐藏下半身，保留玩家皮肤、宽臂/slim 区分与消散闪烁。仅亡灵之主召唤的继续原主动远距追击与号令；其余亡灵在出生点附近游荡，玩家靠近 **12 格**才攻击，离开后返回，临时枪械目标也不能绕过限制。细节见 [night-undead.md](night-undead.md)。

## 技术与清理

- `NightEvent` 一次注册初始化、开局、真实死亡和收尾事件。元数据通过现有 `SRERole.setEventEnableChance` 声明，没有修改 SRERole 基类。初始化决定本局结果，正式开局事件沿用该结果，不二次随机。
- `NightRoundState` 分离下一局请求、本局配发和死亡去重；命令只写下一局请求，不写当前局的正式开局掷骰标志。
- 现有 `SREWorldBlackoutComponent` 同步一个 `nightEvent` 标记，无额外组件或逐帧网络包。维护灯具原始 LIT/ACTIVE 属性快照，只更新改变的方块，每秒发现新加载灯具。重置 / 临时停电均受锁保护。
- 快照写入世界 NBT；重启不续跑旧对局，仅用快照恢复灯光，防止关灯永久污染地图。不覆盖被替换成其他方块的灯具。
- `WorldRendererMixin` 在现有效果、地图雾等计算之后统一收紧至16格；事件退出显式清理旧的雾状态，避免带回大厅。
- 局末、世界卸载、停服均撤销黑夜锁、恢复原灯光与时间、清除本局亡灵。区块重载的黑夜亡灵还检查当前会话 ID 集合，旧局实体不能在新局重新生效。

## 验证和游戏内验收

自动检查覆盖下一局请求消费与顺延、0概率、配发去重与失败重试、死亡去重及复活后重杀、雾上限、来源迁移、三维12格边界和出生点约束。

```bash
./gradlew test --tests '*Night*' --tests '*Halloween*' --tests '*Pumpkin*' remapJar
```

仍需多人客户端验收：
1. 普通局没有黑夜；管理员排队后只有下一局生效，重复指令不叠加。
2. 开局 / 轮选开局提示和每人手电筒；满背包、重连不丢失或重复配发。
3. 修电与商城开灯不能提前解除；会议、跨维度和局末不残留雾 / 灯光。
4. 护盾挡下的攻击不生成亡灵；真实死亡生成一只，复活后重死允许新生成；万圣节同开不双生。
5. 非领主亡灵在12格外不追击，12格内攻击，离开后返家；领主的号令和感染不退化。
6. Steve / Alex 皮肤都仅显示半透明上半身，没有额外的不透明底层。
