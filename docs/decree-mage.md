# 律令法师

## 已确认规则

- 普通平民阵营职业 `noellesroles:decree_mage`，复用技能键打开编辑页。
- 页面为“此地禁止______”，词库点击补全或手动输入完整词条，服务端只接收固定 ID，确认成功后扣局内金币、记录已用律令并进入冷却。
- 通常冷却 65 秒，正式开局冷却 80 秒。关闭或打开页面不消耗冷却。
- 每位法师每条律令单局限用一次，使用记录由 RoleData 同步给本人。
- 领域是跟随法师移动的 15 格球形范围，进场生效、离场解除。本人同样受限，只有“禁止光明”豁免本人。
- 禁止杀人持续 7 秒，只限制受律令约束者的即时击杀，不追溯毒、流血、燃烧等延迟伤害；其他律令持续 11 秒。
- 禁止复活同时约束施术者、死亡目标和领域内尸体，自动复活被暂缓，不直接消耗复活资格。

## 技术边界

- 领域权威状态与可清除的药水标记分离。入离场和每秒校准发轻量包，渲染只读本地缓存，不逐帧发包。
- 神圣感通过本地金白光晕、文字渐显、短促震屏和瞬时曝光视觉叠层表达，不更改用户持久亮度/光影设置。
- 法师发光只影响领域内观察者，不给法师全局发光药水。
- 专用 speaker 在固定后台线程创建、使用和释放 Windows SAPI，优先中文系统男声，无男声时保留系统默认音色；不保证所有系统安装相同声线。
- 法师离线、死亡、换职业、游戏结束都会结束领域。原先已有的同类药水效果以短租托管方式恢复，防止退出领域误清其他来源效果。

## 通用技能开局冷却 API

`RoleSkill.Definition.initialCooldownTicks()`，Builder 支持 `.initialCooldownTicks(ticks)` / `.initialCooldownSeconds(seconds)`；默认 0，旧构造器保留。

职业初始化在全部组件与职业钩子执行完后应用初始冷却；`OnGameTrueStarted` 再重置为完整时长。它不改变 `.cooldownSeconds(...)` 的重复施法冷却，也不迁移其他职业原有自定义计时。
