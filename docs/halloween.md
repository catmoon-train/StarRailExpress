# 万圣节小镇活动

## 启用

仅在谋杀模式（包括继承 `SREMurderGameMode` 的模式）中生效，默认关闭。
在存档 `train_maps/<地图ID>.json` 的 `settings` 中加入：

```json
{
  "halloweenEventEnabled": true
}
```

也可用地图开发工具的「地图事件」设置，或原有地图设置命令修改该字段后保存地图。
不要仅靠地图名称判断活动。普通地图不受活动机制影响。

地图中放两个原版或列车发光南瓜灯，两处都用于生成万圣残月。
NPC 使用项目已有 `starrailexpress:textures/block/plush/canyuesama.png` 本地皮肤，不依赖联网拉取。
奖励池、兑换价格及活动时长在世界根目录 `halloween.json` 中调整，下局重新读取。
完整参数与默认表见 [道具说明](halloween-items.md)、[小镇说明](halloween-village.md)、[战斗说明](halloween-combat.md)。

本轮新增南瓜精、独立任务掉落、橙色天空与背景音乐占位，骨剑调整为3耐久/30秒冷却。
玩家完整更新说明见 [万圣节小镇更新公告](halloween-player-update.md)。

## 灵魂链接

手持灵魂链接，右键三格内另一存活玩家发起邀请。对方在确认界面点击绿色羊毛接受、红色羊毛拒绝；15 秒不回应失效。
成功后消耗一个灵魂链接道具，不允许自连、重复连接或同一玩家同时参与多个链接。

- 两人潜行空手右键伙伴，打开同一份 27 格共享物品栏；物品只有一份，不复制两人的原背包。
- 普通盾、临时盾组成共享池，保留每层盾的可见性与原到期时间。优先消耗受击者的盾，再消耗伙伴的盾。
- 一方真实死亡，另一方一同死亡。链接在死亡前解除，避免递归死亡；共享物品只掉落一次。
- 绳索可见，距离不能超过 10 格。越界者被拉回合法位置；遇到碰撞时回到伙伴处。
- 离线、跨维度解除链接并掉落共享栏内容；回合结束清空共享栏，不把局内物品带入下一局。

## 商店与职业

活动局中，实际背包商店有刀商品的玩家，额外能以 200 金币购买 8 耐久的献血锯子。
以商店实际商品为准，不只检查杀手标签，兼容特殊职业商店。

活动地图职业分配时保证出现亡灵之主，优先替换一个已经分配的杀手，不额外增加杀手人数。
亡灵之主新版见 [职业重做](undead-lord-rework.md)。

## 分支同步约定

万圣节使用独立功能提交，同步到 `ltsc-master` 时只 cherry-pick 这些提交，不合并整个 `master`，不夹带其他功能或未跟踪文件。
