# 纵火犯：职业与相关物品完整介绍

## 阵营、目标与收入

- 中立阵营，独立胜利，与消防员绑定生成；保留40格纵火犯透视，在杀手直觉中显示为好人。
- 每完成一个任务获得10金币。
- 每成功给一名当前未浇油的存活目标新增浇油标记，获得35金币。汽油桶、大油罐、火枪共用此规则；重复命中已标记目标不发钱，点火、击杀不额外发这35金币。
- 纵火时刻失败前，纵火犯存活时阻止普通杀手/乘客胜利，但主计时耗尽仍正常进行TIME结算（保留最新上游修复）；时刻失败后放行普通阵营结算，不会下一tick又重新锁局。既有独立胜利优先级不改，保留布谷鸟优先于纵火犯。
- 只有杀光其他存活玩家、成为唯一存活者才能获得纵火犯独立胜利，不再因存活满80秒获胜。

## 初始道具：汽油桶

右键玩家浇油。沿用原有随存活人数变化的汽油桶冷却，不再让打火机进入冷却。标记只统计当前其他存活且仍有油的玩家，不包含纵火犯自己、死亡或已清油目标。

## 初始道具：打火机

- 打火机没有冷却；浇油人数不足时第一次右键警告，3秒内再次右键会点火失败烧死自己（保留远端最新调整）。
- 点火要求为当前其他存活玩家人数的80%，人数向上取整，最低1人。领袖追随者的喷火加成保留远端实现，不再降低点火所需人数。
- 不满足门槛时第一次仅提示标记进度，不点燃其他玩家；须注意3秒内再次右键的点火失败惩罚。
- 满足门槛后先进入过场，过场结束才点燃全部已浇油标记的存活玩家。燃烧等待沿用 `burnDurationSeconds` 配置，不是立即死亡；目标可看见自己的燃烧进度。
- 点火成功同时开始纵火时刻；不能重复点火刷新时刻或重复领取护盾。

## 商店：大油罐（280金币）

- 一次性消耗品，成功投掷后消耗1个；生成失败不扣物品。
- 右键远程投掷，镜头平滑跟随油罐；不把相机实体切到油罐，视角朝向始终由玩家鼠标决定，服务端也不再回传视角，避免强制转向与逐tick抖动。用WASD和视角操控飞行方向，空格上升、潜行下降，复用银翼的控制包和已有按键。
- 油罐作为普通实体渲染在镜头前方，飞行中玩家能看见油罐本体与拖尾；跟随镜头做墙体裁剪，不会钻进方块。
- 落地或碰撞后，给落点半径4.5格球形范围内的其他存活玩家浇油，每个有效新增标记奖励35金币。
- 成功发射开始60秒冷却；同一纵火犯只能操控一个油罐。落地、超时、越界、死亡、退出时回收实体并结束跟随镜头。

## 商店：火枪（50金币）

- 继承左轮物品类和枪械射线语义，单独覆盖服务端开火行为，射程20格。
- 每次开枪消耗100金币；金币不足不能开枪，不扣费、不进入射击冷却。
- 命中玩家只浇油，不造成伤害、不致死，也不会因击中好人掉落枪或消耗枪。
- 每次实际开枪后，不论命中或打空，一律冷却30秒。成功新增标记按统一规则奖励35金币。

## 纵火时刻（80秒）

- 阶段先播放约6秒过场：纵火犯抛出打火机、镜头升至地图俯瞰、场地渐燃、火焰覆盖屏幕，再逐字出现“纵火时刻”，每个字有独立震屏和音效。过场期间暂停交战、主计时与80秒阶段计时；结束后才开始初始燃烧和正式80秒战斗。
- 开始时按全部存活玩家（含自己）每满3人额外获得1层普通护盾，最多4层，少于3人不给盾；只在触发时计算和发放一次。
- 皮肤切换为疯魔皮肤，获得速度II和无限体力；退出时恢复原有速度效果的正确剩余时长。不启动真正疯魔，因此不会附带疯魔的刀具、无敌等无关机制。
- 获得喷火枪，期间可自由切换手持物品但不能丢弃；结束时清理阶段武器，恢复已暂存的原主手物品。
- 必须杀光其余存活玩家才能获胜；最后一tick同时杀光与超时时，杀光优先。80秒结束仍有对手存活时，结束时刻并将主倒计时直接设为“其他存活人数×30秒”（不含纵火犯，不是追加时间），解除锁局，恢复正常结算。
- 超时失败会恢复原主手物品，关闭喷火枪、疯魔皮肤、无限体力和客户端火焰表现，并发送全局失败提示；不为纵火犯宣胜。

## 纵火时刻武器：喷火枪

- 独立自制三维模型：47个方块元素构成深铁枪身、长空心喷嘴、环形枪口、红橙燃料罐、握把、护手、铜管和顶部火力表；配置第一/第三人称左右手、GUI和地面显示。
- 长按右键喷火，以视线为轴的前方5格、半角35度（总锥角70度）三维锥，与短管霰弹枪同款；按玩家碰撞箱8角+中心取样，任一点入锥即命中，仍须通过墙体遮挡检查。
- 每tick（0.05秒）对每个被命中的其他存活玩家增加5%燃烧值，连续命中20tick即可叠满；燃烧值保留、不自动衰减，达到100%后烧死。
- 火力仍每0.1秒（2tick）消耗1.5%，独立于每tick伤害，不按命中人数重复扣火力。整数1000点代表100%火力，避免小数误差。
- 火力耗尽自动进入6.5秒（130tick）填充，结束后回满100%；按原有R键手动填充同样6.5秒，满火力不重复填充。
- 喷火改为从左右手对应枪口喷出的连续火束和自行推进的火焰精灵；显式控制方向、速度、寿命、射线碰撞，完全不依赖原版FLAME随机向量。移除旧的锥口圆环、母线和分散体积粒子；服务端仍每0.1秒仅发一个参数包，命中和火力判定保持权威。

## HUD与受击反馈

- 纵火犯准备面板：浇油进度/80%门槛，火枪每发费用与冷却，大油罐冷却。
- 私有面板显示火力与填充进度；全体玩家另有与阿蒙同款的顶部“纵火时刻”状态栏，显示剩余秒数和比例，过场暂停时不走表，结束显式移除。
- 纵火犯可在32格内其他存活玩家头顶查看燃烧值；文字和条形背景使用普通深度测试，不新增隔墙透视。
- 被点燃或喷火命中的玩家可独立看到自己的燃烧百分比和进度条，不依赖纵火犯是否在本地实体追踪范围内。
- 时刻外观使用单独公开包，仅含纵火犯UUID、阶段开关和剩余时间，不公开私有浇油名单；中途加入按剩余时长同步渐燃进度。

## 死亡规则与兼容

本职业烧死的玩家会生成燃烧尸体，燃烧3秒（60tick）后销毁。尸体燃烧期间不可交互，销毁不依赖纵火犯继续存活；目标同时有火焰冲击和专属屏幕特效。仍无附身、强制禁言或纵火犯死亡后复活。

不修改模组版本，不新增依赖，不新增按键绑定，不修改通用SRERole。

## 纵火时刻场景表现与击杀提示

- 所有玩家在纵火时刻期间带浅橙色全屏滤镜，屏幕四周保留动画火焰边框。
- 过场俯瞰按地图范围采样假火并渐燃，最多256处；正式战斗近景最多96处。仅使用已经加载的地面，不放置真实火方块。
- 纵火犯全身由动画火焰面与本地火焰粒子环绕；第一人称不在自己镜头中央叠全身火焰，使用四周火焰提示。
- 场地和全身火焰纯客户端渲染，不放置真实火方块、不破坏地图，也不通过实体着火增加额外伤害。
- 时刻结束、离线或换世界时清理对应视觉缓存。
- 取消原来的逐人击杀顶部broadcast和聊天提示，保留音效、尸体燃烧及受害者效果。

## 管理员时刻指令

需要权限等级2，在ACTIVE对局内对存活目标使用。省略玩家时作用于执行者，控制台必须指定玩家；目标会自动变为对应职业，再通过真实初始化入口触发时刻。已有相同时刻不会重复转职、刷新计时或重发奖励。

```text
/moment amon [玩家]          # 阿蒙时刻
/moment devil_sister [玩家]  # 恶魔之妹时刻（芙兰朵露）
/moment arsonist [玩家]      # 纵火时刻
/moment infected [玩家]      # 疫使时刻
```

- 指令跳过成熟宿主、浇油门槛、阵营人数、医生与剩余时间等自然触发条件，复用原有广播、音效、状态、物品与回放初始化。
- 纵火时刻指令只开启阶段，不预先点燃其他玩家。
- 保留阿蒙与亡命徒互斥、恶魔之妹的安全时间/技能禁用保护；被保护规则拒绝时会明确反馈，不回滚已经更换的职业。
- 疫使为全局时刻，强制触发后不再因自然条件不满足而立即关闭；新转职的疫使可加入已开启的阶段。

## 过场资源与恢复边界

- 使用原有AdvancedCameraSequence/AdvancedCameraPayload轨道，结束显式飞回各自眼睛位置并恢复视角；标题使用独立时钟，不因战斗暂停而停住。
- 临时预览只发送地图矩形中已加载FULL区块，半径上限32chunk、最多512份快照；不生成新地形、不添加持久票据。超出范围或未加载部分会裁剪并告警。
- 临时提升客户端视距与区块缓存，结束/取消/离线恢复，不保存或永久更改用户配置；原区域被覆盖的快照会补回。
- 中途加入按已进行的过场时间同步；取消或职业切换时解除暂停、恢复原药效剩余时间、清理镜头、滤镜、状态栏和临时区块。
