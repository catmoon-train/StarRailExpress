# 纵火犯：职业与相关物品完整介绍

## 阵营、目标与收入

- 中立阵营，独立胜利；保留40格纵火犯透视，在杀手直觉中显示为好人。
- 每完成一个任务获得10金币。
- 每成功给一名当前未浇油的存活目标新增浇油标记，获得35金币。汽油桶、大油罐、火枪共用此规则；重复命中已标记目标不发钱，点火、击杀不额外发这35金币。
- 纵火犯存活时，普通杀手/乘客胜利及时间耗尽均不结束游戏。锁局方式参考阿蒙终幕：独立计时，不冻结全局游戏时间。既有独立胜利优先级不改，保留布谷鸟优先于纵火犯。
- 杀光其他玩家成为唯一存活者，或在纵火时刻存活满80秒，获得独立胜利。

## 初始道具：汽油桶

右键玩家浇油。沿用原有随存活人数变化的汽油桶冷却，不再让打火机进入冷却。标记只统计当前其他存活且仍有油的玩家，不包含纵火犯自己、死亡或已清油目标。

## 初始道具：打火机

- 完全取消冷却，也取消旧的点火不足自杀。
- 点火要求为当前其他存活玩家人数的80%，人数向上取整，最低1人。沿用领袖追随者所需人数减2、最低1人的既有加成。
- 不满足门槛时仅提示标记进度，不点燃、不伤害任何人，也不伤害纵火犯自己。
- 满足门槛后，点燃全部已浇油标记的存活玩家。燃烧等待沿用 `burnDurationSeconds` 配置，不是立即死亡；目标可看见自己的燃烧进度。
- 点火成功同时开始纵火时刻；不能重复点火刷新时刻或重复领取护盾。

## 商店：大油罐（280金币）

- 一次性消耗品，成功投掷后消耗1个；生成失败不扣物品。
- 右键远程投掷并切换相机，用WASD和视角操控，空格上升、潜行下降，复用银翼的控制包和已有按键。
- 落地或碰撞后，给落点半径4.5格球形范围内的其他存活玩家浇油，每个有效新增标记奖励35金币。
- 成功发射开始60秒冷却；同一纵火犯只能操控一个油罐。落地、超时、越界、死亡、退出时回收实体和相机。

## 商店：火枪（50金币）

- 继承左轮物品类和枪械射线语义，单独覆盖服务端开火行为，射程20格。
- 每次开枪消耗100金币；金币不足不能开枪，不扣费、不进入射击冷却。
- 命中玩家只浇油，不造成伤害、不致死，也不会因击中好人掉落枪或消耗枪。
- 每次实际开枪后，不论命中或打空，一律冷却30秒。成功新增标记按统一规则奖励35金币。

## 纵火时刻（80秒）

- 参考阿蒙时刻的独立终幕状态机，使用80秒计时；会议、时停期间计时和喷火结算暂停。
- 开始时额外获得1层普通护盾，仅给一次，不持续补盾。
- 皮肤切换为疯魔皮肤，获得无限体力；不启动真正疯魔，因此不会附带疯魔的刀具、无敌等无关机制。
- 主手固定持有喷火枪，阻止切槽、换手、丢弃和背包搬动；原主手物品暂存，死亡、离线、换职业、结束时恢复。
- 存活满80秒或杀光其余玩家获胜；死亡后解除本职业锁局，清理阶段、皮肤、火力和燃烧HUD。

## 纵火时刻武器：喷火枪

- 独立自制三维模型：47个方块元素构成深铁枪身、长空心喷嘴、环形枪口、红橙燃料罐、握把、护手、铜管和顶部火力表；配置第一/第三人称左右手、GUI和地面显示。
- 长按右键喷火，前方180度半球范围，半径5格，命中需通过墙体遮挡检查。
- 每0.1秒（2 tick）对每个被命中的其他存活玩家增加5%燃烧值；燃烧值保留、不自动衰减，达到100%后烧死。
- 同一结算周期消耗1.5%火力，不按命中玩家数量重复扣火力。整数1000点代表100%火力，避免小数误差。
- 火力耗尽自动进入10秒换装，结束后回满100%；也可按原有换装键R手动换装，同样10秒，满火力时不重复换装。
- 喷火形状由客户端生成，服务端每个喷火周期只发送一个形状包；命中、范围、消耗和伤害全部服务端判定。

## HUD与受击反馈

- 纵火犯准备面板：浇油进度/80%门槛，火枪每发费用与冷却，大油罐冷却。
- 纵火时刻面板：80秒倒计时、火力百分比与进度条、换装倒计时与进度条、当前绑定的R换装提示。
- 纵火犯可在32格内其他存活玩家头顶查看燃烧值；文字和条形背景使用普通深度测试，不新增隔墙透视。
- 被点燃或喷火命中的玩家可独立看到自己的燃烧百分比和进度条，不依赖纵火犯是否在本地实体追踪范围内。
- 时刻外观使用单独公开包，仅含纵火犯UUID和阶段开关，不公开私有浇油名单。

## 死亡规则与兼容

所有本职业烧死的玩家不生成尸体。彻底取消原有附身、强制禁言与纵火犯死亡后复活机制，纵火时刻内外一致；纵火犯死亡不会复活任何已死玩家。

不修改模组版本，不新增依赖，不新增按键绑定，不修改通用SRERole。
