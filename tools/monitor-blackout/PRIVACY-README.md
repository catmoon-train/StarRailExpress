# 独立本地隐私屏（实验性）

这是独立于旧版 DDC 工具的新程序 `PrivacyScreen-fullscreen.exe`。不依赖显示器的 DDC/CI，不调用向日葵的内部接口，不修改或注入向日葵，不安装驱动。没有远程连接也能运行。原生全屏版另用新文件名，避免覆盖正在运行的旧版 `PrivacyScreen.exe` / `PrivacyScreen-session.exe`；请先正常退出旧版再启动新版。

## 使用

1. 先恢复显示器并正常退出旧版 `MonitorBlackout.exe` / `MonitorBlackout-compat.exe`，避免它们占用 **Ctrl+Alt+F12**。
2. 在被控电脑的本机桌面会话中，双击 `PrivacyScreen-fullscreen.exe` 或 `start-privacy.bat`。不需要管理员权限，启动程序本身不会黑屏。
3. 点击 **开始 60 秒测试**：全部显示器显示黑色，控制窗口自动隐藏到托盘，不留下控制窗口的标题栏和按钮。先从向日葵确认远程画面是否正常，并测试点击、拖动和键盘输入。60 秒后自动撤掉黑色窗口；可从托盘菜单“显示控制窗口”重新打开控制界面。
4. 确认远程画面、输入和恢复均正常后，可勾选 **我已通过向日葵测试，持续运行直到手动恢复**，点击开始并确认。程序可在没有远程连接时持续运行；保持进程运行即可，不会随向日葵断开而自动停止。
5. 恢复方式：**Ctrl+Alt+F12**、远程控制窗口中的“恢复显示”按钮、托盘菜单“恢复显示”、双击托盘图标，或运行 `restore-privacy.bat`。关闭程序会撤掉窗口。

命令行也可恢复：

```bat
PrivacyScreen-fullscreen.exe --restore
```

恢复命令须与运行中的程序处于同一 Windows 用户、会话和权限级别。快捷键注册失败时，程序禁止启动隐私屏；关闭占用快捷键的软件后重新启动本程序。

## 原理和支持范围

每个显示器创建一个原生 Win32 顶层窗口，通过自定义绘制用固定黑色画刷填满客户区，不依赖主题颜色，不使用 WinForms 遮罩窗体，也不通过“最大化”覆盖工作区。每次维持状态均按显示器完整边界设置位置和尺寸，检查窗口及纯黑客户区范围，覆盖任务栏所在区域。无标题栏、边框、最小化／最大化／关闭按钮，不激活，可点击穿透，不显示在任务栏。显示前调用 Windows `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，并读回确认属性值 `0x11`，请求系统从兼容的屏幕捕获路径中排除这些窗口。不使用 `WDA_MONITOR` 作为降级方案。

要求 Windows 10 2004（内部版本 19041）及以上或 Windows 11，桌面合成启用，建议 .NET Framework 4.8。程序启用逐显示器 DPI 感知并按每个显示器的完整边界覆盖，包括负坐标副屏。Windows 版本过旧、快捷键无法注册或首次捕获排除设置失败时，不会退回普通黑色遮罩。首次启动时所有窗口准备好捕获排除才开始显示，初始化或显示失败会撤掉本次新窗口。运行中的维护失败则保留现有窗口，等待重试；不能因此断言捕获排除仍有效。

**重要：Windows 接受捕获排除不等于向日葵一定支持。** 某些采集路径、显卡驱动、远控版本会忽略此属性，导致远程画面也黑屏或异常。必须先做 60 秒测试；不能将 API 成功当成远程兼容性验证。这不是调用向日葵官方隐私屏，也不能保证与其效果一致。

## 限制和恢复

- 显示器保持开机，LCD 背光仍亮；不是物理关屏或节能模式。系统硬件鼠标指针可能仍可见。
- 不禁用本地或远程鼠标键盘，黑色窗口不接管焦点。它不是安全锁屏，也不阻止本地人员退出程序。
- UAC 安全桌面、Ctrl+Alt+Delete 界面、系统提示、其他置顶程序或独占全屏可能出现在黑色窗口上方，不保证始终保密。
- 会话状态或显示器配置改变时，不再主动停止隐私屏：保留现有窗口，按当前显示器布局重新设置并验证捕获排除。新窗口全部准备并显示后才销毁旧窗口；失败时只清理本次新窗口，保留旧窗口并约每秒重试，相同错误不重复刷日志。旧窗口可能无法完全覆盖已改变的布局，重建成功前不保证覆盖完整或捕获排除有效。
- 系统事件不会重置运行模式或 60 秒测试计时；测试到期和手动恢复仍会撤屏。恢复后收到延迟的系统事件不会自行重启隐私屏。
- Windows 锁屏、UAC 安全桌面和其他用户桌面不属于本进程可覆盖的桌面；返回原桌面后会尝试恢复遮罩。注销会结束程序，切换用户不等于在另一用户会话中自动启动，无法保证跨这些边界始终黑屏。
- 程序不自动随 Windows 开机启动，不隐藏进程，不自动修改电源策略；原有的自动睡眠策略仍会生效。
- 正常退出或进程被终止后，Windows 会销毁这些窗口，不需要恢复显示器硬件电源。如果程序线程卡死，自动计时和快捷键也可能不能及时处理；可通过系统任务管理器结束 `PrivacyScreen-fullscreen.exe`。
- 程序不修改 `G:\AweSun` 中的安装文件、驱动或服务。

## 构建和不遮屏验证

双击 `build-privacy.bat` 用系统 .NET Framework 编译器生成 `PrivacyScreen-fullscreen.exe`，无第三方依赖。保留旧版隐私屏、DDC 工具及其构建脚本。

```bat
start /wait "" PrivacyScreen-fullscreen.exe --self-test "%TEMP%\privacy-self-test.txt"
start /wait "" PrivacyScreen-fullscreen.exe --probe "%TEMP%\privacy-probe.txt"
```

- `--self-test`：模拟多显示器生命周期、首次初始化／显示失败回滚、维护失败时不撤屏、重建失败保留旧窗口、先显示新窗口再销毁旧窗口、重建后重试与手动停止、会话变化通知不停止且停止后不重开、空／无效区域、60 秒超时边界与持续模式不超时，及控制界面默认状态。不会显示真实黑色窗口或写入显示器电源。
- `--probe`：创建一个**不显示**的小窗口，验证负坐标位置、窗口与客户区完整尺寸、无装饰样式、捕获排除属性重新设置，并将原生客户区绘制到内存位图逐像素检查纯黑。不会遮屏或写入显示器电源，也不会验证锁屏／重连或向日葵的实际采集行为。
