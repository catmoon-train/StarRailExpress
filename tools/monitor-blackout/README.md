# 外接显示器持续关屏工具

> 不依赖 DDC 的独立本地隐私屏使用原生全屏版 `PrivacyScreen-fullscreen.exe` / `start-privacy.bat`，详见 `PRIVACY-README.md`。请先正常退出旧版 `PrivacyScreen.exe` / `PrivacyScreen-session.exe`。以下是旧版 DDC 工具说明。

独立 Windows 程序，与 Minecraft 模组无关。通过 Windows DDC/CI 接口向外接显示器发送 VCP `0xD6 = 4`（DPM Off）指令，每隔约 3 秒重发。不创建黑色遮罩、不禁用鼠标键盘、不修改向日葵、不安装驱动，不改动系统休眠策略。

## 使用

1. 在**被向日葵控制的电脑**上运行。先在显示器实体菜单中开启 **DDC/CI**。线缆、转接器和显卡驱动也须支持透传 DDC。
2. 双击新版 `MonitorBlackout-compat.exe` 或 `start.bat`，勾选要关闭的显示器。若旧版正在运行，请先恢复显示器并正常退出旧版。
3. 首次保留默认的“60 秒后自动恢复”，点击“开始持续关屏”。确认实体屏幕黑屏，同时向日葵仍能看到桌面、移动鼠标、输入文字。
4. 普通模式测试正常并恢复后，取消“60 秒后自动恢复”，再次点击“开始持续关屏”，即可持续运行到主动恢复。兼容模式始终强制 60 秒测试。
5. 点击“恢复显示器”或在被控电脑按 **Ctrl + Alt + F12** 恢复。远控软件可能截获快捷键，请优先从远程窗口点击恢复按钮。正常关闭窗口也会尝试恢复。

程序要保持运行。支持多显示器选择，且同一 Windows 会话只允许运行一个实例。普通模式下，无法读取 DDC 电源状态的设备不会被强行关屏。已确认原本关闭的设备会跳过；只恢复本次尝试关屏的设备。恢复返回失败的设备保留在恢复列表，可重试。

## 兼容模式：读取电源接口失败时尝试

适用于日志出现“无法读取 DDC 电源接口”，但希望测试设备是否仍接受写入指令的情况。**不代表 LG 22MP55 或其他具体型号已经验证支持。**

关闭旧版程序，再运行新版。勾选“兼容模式：读取失败也尝试关屏”，点击“开始持续关屏”，阅读警告并确认。

- 默认关闭，每次启动测试都需要确认；不自动绕过安全检查。
- 读取失败的设备仍会尝试写入关屏指令；读取成功且已关闭的设备仍然跳过。
- 强制勾选并锁定“60 秒后自动恢复”。计时从确认后开始；驱动调用缓慢时，恢复指令可能延后。
- 写入返回失败的设备也保留恢复记录，因为驱动返回失败不能完全排除硬件已执行的情况。
- 无法读取的设备原有电源状态未知；恢复时会尝试开机，可能开启原本已关闭的设备。只勾选当前已亮且希望测试的显示器。
- 首次务必有人能操作显示器实体电源键。60 秒后只是发送恢复指令，**不保证一定能亮屏**。向日葵是否受影响仍需实测。

## 必须了解的限制

- **不保证所有外接显示器可用，也不保证向日葵在关屏后仍能捕获桌面。** 有的显示器关屏后会从系统中断开，导致桌面重排、远程黑屏或冻结。这时请用实体电源键恢复，并使用向日葵官方隐私屏方案。
- 自动恢复是定时**发送恢复指令**，不是硬件保证。有的显示器关屏后停止响应 DDC，可能必须用实体电源键恢复。首次测试应有人在显示器旁。
- 如果设备不响应，请检查 DDC/CI，尝试 HDMI/DP 直连，绕过扩展坞或转接器。亮度接口支持不代表电源接口也支持。
- 此工具不是安全隐私屏：本地人员可以手动开机，系统事件也可能让显示器短暂亮起；重发关屏指令不能保证全程无画面。输入未被屏蔽。
- 正常退出会尝试恢复；强制终止进程、崩溃、掉电或重启不保证执行恢复。遇到问题用实体电源键或断电重接。
- DDC 调用在后台执行，避免阻塞界面；驱动响应缓慢时，恢复需要等待当前调用结束。如果驱动卡死，恢复和定时操作也无法保证及时完成。
- 不关闭电脑、不主动让电脑休眠；电脑原有的睡眠策略仍然生效。程序不会自动随向日葵连接启动或断开后退出。

## 构建

使用 Windows 自带的 .NET Framework C# 编译器与 WinForms，无第三方依赖。建议 Windows 10/11、.NET Framework 4.8。

双击 `build.bat` 可重新生成 `MonitorBlackout-compat.exe`。旧版 `MonitorBlackout.exe` 不会被覆盖。复制新版 EXE 到另一台满足运行要求的电脑即可使用；BAT 和源码不是运行时必需品。

## 不关屏验证

以下命令需要等待进程结束后查看指定的报告文件：

```bat
start /wait "" MonitorBlackout-compat.exe --self-test "%TEMP%\monitor-blackout-self-test.txt"
start /wait "" MonitorBlackout-compat.exe --probe "%TEMP%\monitor-blackout-probe.txt"
```

`--self-test` 使用模拟显示器测试普通模式关屏、重复关屏、不支持设备跳过、恢复失败重试、恢复后不再写入，以及兼容模式读取失败后写入、写入失败后恢复和恢复重试；同时检查 Win32 结构体大小、窗体构造、兼容模式默认关闭和强制定时恢复选项。不会对真实显示器发送电源指令。

`--probe` 只枚举物理显示器并读取 DDC 电源接口，不写入电源状态。检测成功不代表实体关屏及向日葵兼容性已经验证。
